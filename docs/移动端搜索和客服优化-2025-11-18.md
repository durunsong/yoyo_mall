# 移动端搜索和客服优化 - 2025-11-18

## 修改概述

本次优化解决了两个移动端用户体验问题：
1. **搜索框回车功能失效** - 修复搜索框无法通过回车键搜索的问题
2. **客服图标优化** - 将移动端的客服功能移至侧边抽屉菜单，隐藏默认的浮动图标

## 问题描述

### 问题1：搜索框回车键不工作

**现象：**
- 用户在移动端搜索框输入关键词后
- 按回车键无反应
- 必须点击搜索图标按钮才能搜索

**原因：**
- 使用了 `onKeyPress` 事件
- `onKeyPress` 在某些浏览器和输入法下不可靠
- 应该使用 `onKeyDown` 事件

### 问题2：客服浮动图标影响体验

**现象：**
- Tawk.to 客服组件会在页面右下角显示绿色浮动图标
- 移动端屏幕小，浮动图标可能遮挡内容
- 与固定工具栏功能重复

**需求：**
- 移动端隐藏默认的客服浮动图标
- 将客服功能集成到侧边抽屉菜单
- 桌面端保持原有的浮动图标

## 解决方案

### 1. 修复搜索框回车功能

**文件：** `src/components/products/product-search.tsx`

#### 修改内容

**修改前：**
```tsx
const handleKeyPress = (e: React.KeyboardEvent) => {
  if (e.key === 'Enter') {
    handleSearch();
  }
};

// ...

<Input
  onKeyPress={handleKeyPress}
  // ...
/>
```

**修改后：**
```tsx
// 修改为 onKeyDown 以确保回车键能正常触发
const handleKeyDown = (e: React.KeyboardEvent) => {
  if (e.key === 'Enter') {
    e.preventDefault(); // 防止表单提交
    handleSearch();
  }
};

// ...

<Input
  onKeyDown={handleKeyDown}
  // ...
/>
```

#### 技术说明

**为什么使用 onKeyDown 而不是 onKeyPress？**

1. **兼容性更好**
   - `onKeyPress` 在React 17+中已被标记为过时
   - `onKeyDown` 在所有浏览器和输入法下都能可靠触发

2. **事件触发顺序**
   ```
   keydown → keypress → keyup
   ```
   - `onKeyDown` 最先触发，能更快响应用户操作
   - `onKeyPress` 可能在某些特殊键（如Enter）上不触发

3. **添加 preventDefault**
   - 防止在form元素中回车导致表单提交
   - 确保只执行搜索逻辑

#### 额外优化

**搜索按钮增强：**
```tsx
<Button
  type="button"
  variant="ghost"
  size="sm"
  className="absolute right-0 top-0 h-full px-3 hover:bg-accent"
  onClick={handleSearch}
  aria-label="搜索"  // 新增：无障碍标签
```

**改进点：**

### 2. 客服功能优化

#### 2.1 修改 TawkTo Widget 组件

**文件：** `src/components/chat/tawk-to-widget.tsx`

**核心逻辑：**

```tsx
window.Tawk_API.onLoad = function () {
  console.log('Tawk.to 客服已加载');
  
  // 在移动端隐藏 Tawk.to 的默认图标
  // 移动端宽度小于 768px
  const isMobile = window.innerWidth < 768;
  if (isMobile) {
    window.Tawk_API.hideWidget();
  }
};

// 监听窗口大小变化，动态显示/隐藏客服图标
const handleResize = () => {
  if (window.Tawk_API) {
    const isMobile = window.innerWidth < 768;
    if (isMobile) {
      window.Tawk_API.hideWidget();
    } else {
      window.Tawk_API.showWidget();
    }
  }
};

window.addEventListener('resize', handleResize);
```

**功能说明：**

1. **加载时判断设备**
   - 检测屏幕宽度
   - 移动端（< 768px）自动隐藏默认图标
   - 桌面端（≥ 768px）显示默认图标

2. **响应式适配**
   - 监听窗口大小变化
   - 用户切换设备方向或调整窗口大小时自动适配
   - 确保在任何情况下都能正确显示/隐藏

3. **清理函数**
   ```tsx
   return () => {
     // 移除resize监听
     window.removeEventListener('resize', handleResize);
     // ... 其他清理
   };
   ```
   - 组件卸载时移除事件监听
   - 防止内存泄漏
