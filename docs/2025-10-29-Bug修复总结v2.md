## 🐛 本次修复的问题

### 1. Analytics API 500 错误 ✅

**错误信息**:
```
GET http://localhost:3000/api/admin/analytics?period=30 500 (Internal Server Error)
```

**根本原因**:
- Order 模型的字段名是 `totalAmount`,不是 `total`
- API 中多处使用了错误的字段名

**修复内容**:
修改 `src/app/api/admin/analytics/route.ts` 中所有字段名:
- `_sum.total` → `_sum.totalAmount`
- `order.total` → `order.totalAmount`
- 共修改 6 处

**影响范围**:
- 数据看板页面
- 仪表板页面
- 所有依赖 Analytics API 的功能

---

### 2. 商品价格显示错误 ✅

**错误信息**:
```
TypeError: product.price.toFixed is not a function
at src/app/admin/products/page.tsx:504:47
```

**根本原因**:
- Prisma Decimal 类型不能直接调用 JavaScript 的 toFixed 方法
- 需要先转换为 Number 类型

**修复内容**:
修改 `src/app/admin/products/page.tsx`:
```tsx
// 修复前
${product.price.toFixed(2)}

// 修复后
${Number(product.price).toFixed(2)}
```

**影响范围**:
- 商品管理页面
- 商品列表显示

## 📝 技术要点

### Prisma Decimal 类型处理
```tsx
// ❌ 错误用法
product.price.toFixed(2)

// ✅ 正确用法
Number(product.price).toFixed(2)

// ✅ 或者使用 toString
product.price.toString()
```

### 字段名一致性
```typescript
// 确保 API 和数据库字段名一致
// schema.prisma
model Order {
  totalAmount Decimal @db.Decimal(10, 2)  // ✅ 使用 totalAmount
}

// API 查询
_sum: {
  totalAmount: true  // ✅ 使用 totalAmount
}
```
