# 后台搜索和通知功能使用指南

## 🔍 搜索功能

### 功能概述
后台全局搜索支持快速查找商品、订单和用户信息,提供实时搜索结果和键盘导航。

### 使用方法

#### 1. 基本搜索
```
1. 在后台顶部找到搜索框
2. 输入关键词(商品名、订单号、用户名等)
3. 等待搜索结果自动显示(300ms 防抖)
4. 点击结果跳转到详情页
```

#### 2. 键盘快捷操作
```
↑ 键     - 向上选择
↓ 键     - 向下选择
Enter 键 - 确认选择并跳转
ESC 键   - 关闭搜索结果
```

#### 3. 搜索范围

**商品搜索**:
- 商品名称
- SKU 编号
- 商品描述

**订单搜索**:
- 订单号
- 下单用户名
- 用户邮箱

**用户搜索**:
- 用户名
- 邮箱地址

### 搜索技巧

1. **模糊匹配**: 不需要输入完整关键词,部分匹配即可
2. **不区分大小写**: 大小写不影响搜索结果
3. **实时搜索**: 输入即搜索,无需按回车
4. **快速导航**: 使用键盘比鼠标更快

### 示例

```
搜索商品:
- 输入 "iPhone" 查找所有 iPhone 相关商品
- 输入 "SKU123" 查找特定 SKU 的商品

搜索订单:
- 输入 "ORD-12345" 查找订单号
- 输入 "张三" 查找用户的订单

搜索用户:
- 输入 "user@example.com" 查找用户
- 输入 "李四" 查找用户信息
```

## 🔔 通知功能

### 功能概述
通知中心实时提醒重要事件,包括新订单、库存预警、新用户注册等。

### 通知类型

#### 1. 订单通知 🛒
- **触发条件**: 有新的待处理订单
- **时间范围**: 最近 24 小时
- **通知内容**: 订单号、用户、金额
- **操作**: 点击跳转到订单详情

#### 2. 商品通知 📦
- **触发条件**: 商品库存 ≤ 10
- **通知内容**: 商品名称、当前库存
- **操作**: 点击跳转到商品管理

#### 3. 用户通知 👤
- **触发条件**: 有新用户注册
- **时间范围**: 最近 24 小时
- **通知内容**: 用户名、邮箱
- **操作**: 点击跳转到用户详情

### 使用方法

#### 1. 查看通知
```
1. 点击顶部导航栏的通知图标(铃铛)
2. 查看未读数量徽章
3. 下拉查看通知列表
4. 点击通知跳转到相关页面
```

#### 2. 管理通知

**标记已读**:
- 点击单个通知自动标记为已读
- 点击"全部已读"批量标记

**删除通知**:
- 点击通知右侧的删除按钮(垃圾桶图标)

**筛选通知**:
- 在通知中心页面切换"全部"/"未读"

#### 3. 通知中心
```
访问: /admin/notifications

功能:
- 查看所有历史通知
- 筛选未读通知
- 批量标记已读
- 删除通知
- 查看通知详情
```

### 通知设置

#### 刷新频率
- 自动刷新: 每 60 秒
- 手动刷新: 重新打开通知面板

#### 通知数量
- 下拉面板: 最多显示 20 条
- 通知中心: 显示所有通知

### 最佳实践

#### 1. 及时处理
```
✅ 定期查看通知徽章
✅ 及时处理新订单
✅ 关注库存预警
✅ 标记已读保持清爽
```

#### 2. 优先级管理
```
高优先级:
- 新订单通知 → 立即处理
- 库存预警 → 及时补货

中优先级:
- 新用户注册 → 定期查看

低优先级:
- 系统通知 → 有空查看
```

#### 3. 通知清理
```
建议:
- 每天清理已读通知
- 删除不重要的通知
- 保持通知列表整洁
```

## 💡 常见问题

### Q1: 搜索结果为什么没有显示?
**A**: 
- 检查是否输入了关键词
- 确认数据库中有匹配的数据
- 等待 300ms 防抖时间
- 检查网络连接

### Q2: 为什么没有收到通知?
**A**:
- 确认有符合条件的事件(新订单、低库存等)
- 检查时间范围(仅显示最近 24 小时)
- 刷新页面或重新打开通知面板
- 检查管理员权限

### Q3: 通知数量徽章不准确?
**A**:
- 刷新页面
- 重新登录
- 清除浏览器缓存
- 检查是否已标记为已读

### Q4: 搜索速度慢怎么办?
**A**:
- 正常情况下有 300ms 防抖
- 检查网络速度
- 检查数据库性能
- 减少搜索关键词长度

### Q5: 如何关闭通知提醒?
**A**:
- 当前版本暂不支持关闭
- 可以标记全部已读
- 可以删除不需要的通知
- 后续版本会添加通知设置

## 🔧 技术说明

### 搜索实现
- **防抖优化**: 300ms 延迟减少 API 调用
- **并行查询**: 同时搜索商品、订单、用户
- **模糊匹配**: 使用 Prisma `contains` 模式
- **结果限制**: 每类最多 5 条结果

### 通知实现
- **定时刷新**: 每 60 秒自动刷新
- **数据过滤**: 仅显示最近 24 小时
- **状态管理**: 前端状态 + 后端 API
- **权限控制**: 仅管理员可访问
