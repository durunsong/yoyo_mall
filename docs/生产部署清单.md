## 🚀 部署步骤

### Vercel 部署 (推荐)

#### 1. 连接 GitHub 仓库
```bash
# 推送代码到 GitHub
git add .
git commit -m "chore: prepare for production deployment"
git push origin main
```

#### 2. 在 Vercel 创建项目
1. 访问 [vercel.com](https://vercel.com)
2. 点击 "New Project"
3. 选择 GitHub 仓库
4. 配置环境变量
5. 点击 "Deploy"

#### 3. 配置自定义域名
1. 在 Vercel 项目设置中添加域名
2. 更新 DNS 记录
3. 等待 SSL 证书生成

#### 4. 配置 Webhook (Stripe)
```
Webhook URL: https://yourdomain.com/api/payments/stripe/webhook
Events: checkout.session.completed, payment_intent.succeeded
```

---

### Docker 部署

#### 1. 创建 Dockerfile
```dockerfile
FROM node:20-alpine AS base

# 依赖安装
FROM base AS deps
WORKDIR /app
COPY package.json pnpm-lock.yaml ./
RUN npm install -g pnpm && pnpm install --frozen-lockfile

# 构建
FROM base AS builder
WORKDIR /app
COPY --from=deps /app/node_modules ./node_modules
COPY . .
RUN npm run build

# 运行
FROM base AS runner
WORKDIR /app
ENV NODE_ENV production
COPY --from=builder /app/public ./public
COPY --from=builder /app/.next/standalone ./
COPY --from=builder /app/.next/static ./.next/static

EXPOSE 3000
CMD ["node", "server.js"]
```

#### 2. 构建和运行
```bash
# 构建镜像
docker build -t yoyo-mall .

# 运行容器
docker run -p 3000:3000 --env-file .env.production yoyo-mall
```

## 📞 问题排查

### 常见问题

#### 1. 构建失败
```bash
# 清除缓存重新构建
rm -rf .next
pnpm build
```

#### 2. 数据库连接失败
- 检查 `DATABASE_URL` 是否正确
- 确认数据库服务运行中
- 检查防火墙规则

#### 3. 环境变量不生效
- 确认变量名前缀 `NEXT_PUBLIC_`
- 重新构建项目
- 检查 Vercel 环境变量配置

#### 4. 图片加载失败
- 检查 `next.config.mjs` 中的 `remotePatterns`
- 确认图片域名已添加
