### 2. 购物车数据同步

**设计思路**:
- 游客可以使用购物车(本地存储)
- 用户登录后自动同步到服务器
- 智能合并本地和服务器数据
- 跨设备访问购物车

**实现组件**: `CartSync`

```typescript
export function CartSync() {
  const { data: session, status } = useSession();
  const { items } = useCartStore();
  const syncedRef = useRef(false);

  useEffect(() => {
    // 如果用户已登录且购物车有商品,且尚未同步
    if (status === 'authenticated' && items.length > 0 && !syncedRef.current) {
      syncCartToServer();
      syncedRef.current = true;
    }

    // 如果用户登出,重置同步状态
    if (status === 'unauthenticated') {
      syncedRef.current = false;
    }
  }, [status, session, items]);

  const syncCartToServer = async () => {
    try {
      const response = await fetch('/api/cart/sync', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ items }),
      });

      if (response.ok) {
        console.log('购物车数据已同步到服务器');
      }
    } catch (error) {
      console.error('购物车同步失败:', error);
    }
  };

  return null;
}
```

**特点**:
- 使用 `useRef` 防止重复同步
- 登录时自动触发同步
- 登出时重置同步状态
- 静默同步,不打扰用户

### 3. 购物车同步 API

**端点**: `POST /api/cart/sync`

**功能**:
- 验证用户登录状态
- 创建新购物车(如果不存在)
- 合并本地和服务器购物车
- 智能处理商品数量

**核心逻辑**:
```typescript
// 合并本地购物车和服务器购物车
for (const localItem of items) {
  const existingItem = existingCart.items.find(
    (item) =>
      item.productId === localItem.productId &&
      item.variantId === localItem.variantId,
  );

  if (existingItem) {
    // 如果商品已存在,更新数量
    await prisma.cartItem.update({
      where: { id: existingItem.id },
      data: {
        quantity: existingItem.quantity + localItem.quantity,
        totalPrice: (existingItem.quantity + localItem.quantity) * localItem.price,
      },
    });
  } else {
    // 如果商品不存在,添加新商品
    await prisma.cartItem.create({
      data: {
        cartId: existingCart.id,
        productId: localItem.productId,
        variantId: localItem.variantId,
        quantity: localItem.quantity,
        unitPrice: localItem.price,
        totalPrice: localItem.price * localItem.quantity,
      },
    });
  }
}
```

**智能合并**:
- 相同商品 → 累加数量
- 不同商品 → 添加到购物车
- 保留所有数据,不丢失
