### 2. 购物车动画效果

**实现内容**:
- ✅ 添加商品时触发弹跳动画
- ✅ 购物车图标右上角显示数量角标
- ✅ 数量角标支持脉冲动画
- ✅ 数量超过99显示"99+"
- ✅ 悬停时图标放大效果

**技术实现**:
```typescript
// 监听购物车变化触发动画
useEffect(() => {
  if (cartCount > 0) {
    setCartAnimation(true);
    const timer = setTimeout(() => setCartAnimation(false), 600);
    return () => clearTimeout(timer);
  }
}, [cartCount]);

// 购物车按钮动画
<Button
  className={cn(
    'h-14 w-14 rounded-full shadow-lg transition-all hover:scale-110',
    cartAnimation && 'animate-bounce'
  )}
>
  <ShoppingCart className="h-6 w-6" />
</Button>

// 数量角标
{cartCount > 0 && (
  <Badge
    variant="destructive"
    className={cn(
      'absolute -top-1 -right-1 h-6 w-6 rounded-full',
      cartAnimation && 'animate-pulse'
    )}
  >
    {cartCount > 99 ? '99+' : cartCount}
  </Badge>
)}
```

**动画效果**:
- `animate-bounce`: 弹跳动画(600ms)
- `animate-pulse`: 脉冲动画
- `hover:scale-110`: 悬停放大
- `transition-all`: 平滑过渡

### 实时时钟更新

```typescript
const [currentTime, setCurrentTime] = useState(new Date());

useEffect(() => {
  const timer = setInterval(() => {
    setCurrentTime(new Date());
  }, 1000); // 每秒更新

  return () => clearInterval(timer);
}, []);
```
