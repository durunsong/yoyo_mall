# 移动端导航栏优化 - 侧边抽屉菜单改进 - 2025-11-18

## 修改概述

将移动端顶部导航栏的Discord和语言切换功能移至侧边抽屉菜单中，使顶部导航栏更加简洁清爽。

## 问题分析

### 修改前的问题

移动端顶部导航栏功能图标过多，包括：
- 🔍 搜索按钮
- 🛒 购物车图标
- ❤️ 心愿单图标
- 💬 Discord图标
- 🌐 语言切换
- 🔔 通知铃铛
- 👤 用户菜单/登录
- ☰ 汉堡菜单

**问题：**
1. 图标太多，视觉上显得拥挤
2. 在小屏幕设备上可能换行或挤压
3. Discord和语言切换使用频率相对较低，不需要一直显示在顶部

### 优化目标

1. **简化顶部导航栏** - 只保留高频使用的功能
2. **改善用户体验** - 低频功能放到侧边菜单中
3. **视觉更清爽** - 减少顶部图标数量

## 修改内容

### 文件：`src/components/layout/shadcn-header.tsx`

#### 1. 移除顶部的Discord图标（移动端）

**修改前：**
```tsx
{/* Discord按钮 - 在移动端显示 */}
<Button
  variant="ghost"
  size="icon"
  className="md:hidden"
  onClick={handleDiscordClick}
>
  <svg className="h-4 w-4 text-[#5865F2]" viewBox="0 0 24 24" fill="currentColor">
    <path d="M20.317 4.37a19.791..." />
  </svg>
</Button>
```

**修改后：**
完全移除此按钮

#### 2. 隐藏移动端的语言切换（顶部）

**修改前：**
```tsx
{/* 语言切换 */}
<LanguageSwitcher mode="select" />
```

**修改后：**
```tsx
{/* 语言切换 - 仅桌面端显示 */}
<div className="hidden md:block">
  <LanguageSwitcher mode="select" />
</div>
```

**说明：**
- 添加 `hidden md:block` 类
- 在移动端（< 768px）隐藏
- 在桌面端（≥ 768px）正常显示

#### 3. 在侧边抽屉菜单中添加Discord和语言切换

**位置：** 侧边抽屉 Sheet 组件内，导航菜单后，用户操作前

**添加的代码：**
```tsx
<Separator />

{/* Discord 和语言切换 */}
<div className="space-y-2">
  {/* Discord 按钮 */}
  <Button
    variant="outline"
    className="w-full justify-start"
    onClick={() => {
      setMobileMenuOpen(false);
      handleDiscordClick();
    }}
  >
    <svg className="mr-2 h-4 w-4 text-[#5865F2]" viewBox="0 0 24 24" fill="currentColor">
      <path d="M20.317 4.37a19.791..." />
    </svg>
    Discord
  </Button>

  {/* 语言切换 */}
  <div className="flex items-center justify-between rounded-lg border p-3">
    <span className="text-sm font-medium">语言 / Language</span>
    <LanguageSwitcher mode="select" />
  </div>
</div>

<Separator />
```

**设计说明：**

1. **Discord按钮**
   - 使用 `Button` 组件，`variant="outline"` 样式
   - 全宽显示 `w-full`
   - 左对齐 `justify-start`
   - 显示Discord图标和文字标签
   - 点击后关闭菜单并触发Discord功能

2. **语言切换**
   - 使用带边框的容器 `rounded-lg border`
   - 左侧显示标签"语言 / Language"（中英文双语）
   - 右侧放置语言切换组件
   - 采用 flex 布局，两端对齐

3. **分隔线**
   - 在功能组前后添加分隔线
   - 与其他菜单区块保持一致的视觉层次

## 技术实现细节

### 1. CSS类使用

**隐藏移动端显示桌面端：**
```tsx
<div className="hidden md:block">
  <LanguageSwitcher mode="select" />
</div>
```
- `hidden` - 默认隐藏（移动端）
- `md:block` - 中等屏幕及以上显示（桌面端）

### 2. 点击事件处理

**Discord按钮点击：**
```tsx
onClick={() => {
  setMobileMenuOpen(false);  // 关闭抽屉菜单
  handleDiscordClick();       // 触发Discord功能
}}
```

**作用：**
- 点击后先关闭侧边菜单
- 然后执行Discord点击处理
- 避免菜单遮挡toast提示

### 3. 布局设计

**语言切换容器：**
```tsx
<div className="flex items-center justify-between rounded-lg border p-3">
  <span className="text-sm font-medium">语言 / Language</span>
  <LanguageSwitcher mode="select" />
</div>
```

**CSS类说明：**
- `flex` - Flex布局
- `items-center` - 垂直居中对齐
- `justify-between` - 两端对齐
- `rounded-lg` - 大圆角
- `border` - 边框
- `p-3` - 内边距（12px）
