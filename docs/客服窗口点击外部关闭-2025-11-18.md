# 客服窗口点击外部关闭功能 - 2025-11-18

## 功能概述

在PC端（桌面端）实现点击客服对话窗口外部区域时自动关闭客服窗口的交互功能，提升用户体验。

## 需求背景

**用户场景：**
1. 用户点击客服按钮，打开客服对话窗口
2. 查看完信息或发送完消息后
3. 想要继续浏览网页内容
4. 需要手动点击关闭按钮才能关闭客服窗口

**改进目标：**
- 点击客服窗口外的任何区域即可关闭窗口
- 类似于下拉菜单、弹窗的交互体验
- 更符合用户操作习惯

## 实现方案

### 核心思路

1. **监听客服窗口状态**
   - 利用 Tawk.to API 的 `onChatMaximized` 事件
   - 窗口打开时添加点击监听器

2. **检测点击位置**
   - 获取客服iframe元素的位置和大小
   - 判断点击坐标是否在iframe外部

3. **自动关闭窗口**
   - 如果点击在外部，调用 `minimize()` API
   - 移除点击监听器

### 技术实现

**文件：** `src/components/chat/tawk-to-widget.tsx`

#### 1. 监听窗口打开事件

```tsx
window.Tawk_API.onChatMaximized = function () {
  console.log('客服窗口已打开');
  
  // 在桌面端添加点击外部关闭的功能
  if (window.innerWidth >= 768) {
    // 延迟添加监听器，避免立即触发
    setTimeout(() => {
      addClickOutsideListener();
    }, 100);
  }
};
```

**要点：**
- 只在桌面端（≥ 768px）启用此功能
- 延迟100ms添加监听器，避免打开时的点击事件立即触发关闭

#### 2. 监听窗口关闭事件

```tsx
window.Tawk_API.onChatMinimized = function () {
  console.log('客服窗口已最小化');
  // 移除点击外部监听器
  removeClickOutsideListener();
};
```

**作用：**
- 窗口关闭时清理监听器
- 避免不必要的事件监听

#### 3. 点击外部检测逻辑

```tsx
const handleClickOutside = (event: MouseEvent) => {
  // 获取 Tawk.to iframe 元素
  const tawkIframe = document.getElementById('tawkchat-container') || 
                    document.querySelector('iframe[title*="chat"]') ||
                    document.querySelector('iframe[src*="tawk.to"]');
  
  if (!tawkIframe) return;

  // 检查点击是否在 iframe 外部
  const rect = tawkIframe.getBoundingClientRect();
  const clickX = event.clientX;
  const clickY = event.clientY;

  const isOutside = 
    clickX < rect.left ||
    clickX > rect.right ||
    clickY < rect.top ||
    clickY > rect.bottom;

  // 如果点击在外部，关闭客服窗口
  if (isOutside && window.Tawk_API) {
    window.Tawk_API.minimize();
  }
};
```

**检测逻辑：**
1. **查找iframe元素**
   - 尝试通过ID查找
   - 通过title属性查找
   - 通过src URL查找
   
2. **获取边界信息**
   - 使用 `getBoundingClientRect()` 获取位置和大小
   - 得到 left, right, top, bottom 坐标

3. **判断点击位置**
   - 获取点击的 clientX 和 clientY
   - 判断是否在矩形区域外部

4. **执行关闭操作**
   - 调用 `window.Tawk_API.minimize()`

#### 4. 监听器管理

```tsx
// 添加点击外部监听器
const addClickOutsideListener = () => {
  document.addEventListener('click', handleClickOutside, true);
};

// 移除点击外部监听器
const removeClickOutsideListener = () => {
  document.removeEventListener('click', handleClickOutside, true);
};
```

**参数说明：**
- 第三个参数 `true` - 使用捕获阶段
- 在捕获阶段监听可以更早捕获事件
- 避免某些元素阻止事件冒泡导致监听失效

#### 5. 清理函数

```tsx
return () => {
  // 移除点击外部监听器
  removeClickOutsideListener();
  
  // 移除脚本(如果需要)
  const tawkScript = document.querySelector('script[src*="embed.tawk.to"]');
  if (tawkScript) {
    tawkScript.remove();
  }

  // 清理全局对象
  if (window.Tawk_API) {
    window.Tawk_API = undefined;
  }
};
```

**作用：**
- 组件卸载时清理所有监听器
- 防止内存泄漏
- 确保不会影响其他页面

## 设备适配

### 桌面端（≥ 768px）

**启用点击外部关闭：**
- ✅ 打开客服窗口时添加监听器
- ✅ 点击窗口外部自动关闭
- ✅ 点击窗口内部正常使用

**使用场景：**

- 窗口外部有足够的点击区域

### 移动端（< 768px）

**不启用点击外部关闭：**
- ❌ 不添加点击监听器
- ❌ 点击外部不会关闭
- ✅ 需要手动点击关闭按钮

   - 滚动时可能误触外部
   - 需要更明确的关闭意图

   - 移动端用户习惯点击关闭按钮
   - 自动关闭可能让用户困惑

## 技术细节

### 1. 事件捕获阶段

```tsx
document.addEventListener('click', handleClickOutside, true);
```

**为什么使用捕获阶段（true）？**

**事件传播三个阶段：**
1. 捕获阶段（Capture Phase）- 从document到目标元素
2. 目标阶段（Target Phase）- 到达目标元素
3. 冒泡阶段（Bubble Phase）- 从目标元素到document

**使用捕获的优势：**
- 更早捕获事件
- 避免被其他元素的 `stopPropagation()` 阻止
- 确保能检测到所有点击

### 2. 延迟添加监听器

```tsx
setTimeout(() => {
  addClickOutsideListener();
}, 100);
```

**为什么需要延迟？**

**问题场景：**
```
时间线：
0ms   - 用户点击客服按钮
1ms   - 触发按钮点击事件
2ms   - 调用 maximize()
3ms   - 窗口开始打开
4ms   - 触发 onChatMaximized
5ms   - 添加点击监听器
6ms   - 点击事件仍在传播
7ms   - 触发 handleClickOutside
8ms   - 判定为外部点击
9ms   - 调用 minimize()
10ms  - 窗口立即关闭 ❌
```

**解决方案：**
```
时间线：
0ms   - 用户点击客服按钮
1ms   - 触发按钮点击事件
2ms   - 调用 maximize()
...   - 点击事件传播完成
100ms - 延迟结束
101ms - 添加点击监听器 ✅
```

### 3. 多种方式查找iframe

```tsx
const tawkIframe = 
  document.getElementById('tawkchat-container') || 
  document.querySelector('iframe[title*="chat"]') ||
  document.querySelector('iframe[src*="tawk.to"]');
```

**为什么需要多种方式？**

1. **ID可能变化**
   - Tawk.to可能使用不同的ID
   - 不同版本ID可能不同

2. **属性选择更可靠**
   - title通常包含"chat"
   - src一定包含"tawk.to"

3. **容错性**
   - 任意一种方式找到即可
   - 提高兼容性

### 4. 边界检测算法

```tsx
const isOutside = 
  clickX < rect.left ||
  clickX > rect.right ||
  clickY < rect.top ||
  clickY > rect.bottom;
```

**可视化说明：**

```
                top
                 │
    ┌────────────┼────────────┐
    │            │            │
left│   iframe   │   内部     │right
    │            │            │
    └────────────┼────────────┘
                 │
               bottom

点击坐标 (x, y)：
- x < left   → 外部（左侧）
- x > right  → 外部（右侧）
- y < top    → 外部（上方）
- y > bottom → 外部（下方）
- 其他       → 内部
```
