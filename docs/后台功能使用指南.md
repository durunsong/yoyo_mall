# 后台功能使用指南

## 📊 数据看板

### 访问路径
```
/admin/analytics 或 /admin/dashboard
```

### 功能说明

#### 1. 核心指标卡片
- **总营收**: 显示已完成订单的总营收,包含环比增长率
- **总订单**: 显示订单总数,包含环比增长率
- **总用户**: 显示注册用户数,包含环比增长率
- **总商品**: 显示商品库存总数

#### 2. 订单状态统计
- 待处理订单数量(黄色)
- 处理中订单数量(蓝色)
- 已完成订单数量(绿色)

#### 3. 数据图表

**订单趋势图** (折线图)
- 展示订单数量随时间的变化
- 支持切换时间周期: 7天、30天、90天
- 鼠标悬停查看具体数值

**营收趋势图** (折线图)
- 展示营收金额随时间的变化
- 自动格式化为货币显示
- 支持数据缩放和拖拽

**订单状态分布** (饼图)
- 直观展示各状态订单占比
- 点击图例隐藏/显示对应数据
- 显示百分比和具体数值

**用户增长趋势** (柱状图)
- 展示每日新增用户数
- 柱状图清晰对比数据
- 支持数据标签显示

#### 4. 热门商品和最近订单
- 热门商品: 按销量排序的前5个商品
- 最近订单: 最新的5个订单记录

## 📦 商品管理

### 访问路径
```
/admin/products
```

### 功能说明

#### 1. 商品列表
- **搜索**: 支持按商品名称或 SKU 搜索
- **筛选**: 
  - 按分类筛选
  - 按状态筛选(已发布/草稿/已归档)
- **排序**: 按创建时间、价格、库存等排序

#### 2. 添加商品
点击"添加商品"按钮,填写以下信息:
- **基本信息**:
  - 商品名称 (必填)
  - 简短描述
  - 详细描述
- **SKU 和分类**:
  - SKU 编码 (必填)
  - 商品分类 (必填)
- **价格**:
  - 售价 (必填)
  - 划线价 (可选)
- **状态**:
  - 已发布: 前台可见
  - 草稿: 仅后台可见
  - 已归档: 不显示

#### 3. 图片上传 (新功能)
- 支持上传最多 5 张图片
- 第一张图片自动设为主图
- 支持的格式: JPG、PNG、GIF
- 单个文件不超过 5MB
- 可拖拽上传
- 点击删除按钮移除图片

#### 4. 批量操作 (新功能)
- 勾选多个商品
- 批量操作选项:
  - 批量发布
  - 批量下架
  - 批量归档
  - 批量删除

#### 5. 编辑和删除
- 点击编辑图标修改商品信息
- 点击删除图标删除商品(需确认)

## 📋 订单管理

### 访问路径
```
/admin/orders
```

### 功能说明

#### 1. 订单列表
- **搜索**: 按订单号、客户姓名或邮箱搜索
- **筛选**: 按订单状态筛选
  - 待处理
  - 已确认
  - 处理中
  - 已发货
  - 已送达
  - 已取消
  - 已退款

#### 2. 订单统计
- 总订单数
- 待处理订单数
- 处理中订单数
- 已完成订单数
- 总营收

#### 3. 查看订单详情
点击"详情"按钮查看:
- 订单状态和时间
- 客户信息
- 配送地址
- 订单商品列表
- 订单金额明细

#### 4. 更新订单状态
- 点击"更新状态"按钮
- 选择新的订单状态
- 确认更新

#### 5. 批量处理 (新功能)
- 勾选多个订单
- 批量更新状态
- 批量导出数据

#### 6. 数据导出 (新功能)
点击"导出数据"按钮:
- **导出为 CSV**: 适合 Excel 打开
- **导出为 JSON**: 适合数据交换
- 文件名自动包含日期

## 👥 用户管理

### 访问路径
```
/admin/users
```

### 功能说明

#### 1. 用户列表
- **搜索**: 按邮箱或姓名搜索
- **筛选**:
  - 按角色筛选(管理员/客户/访客)
  - 按状态筛选(活跃/不活跃)
- **分页**: 每页显示 20 条记录

#### 2. 用户统计
- 总用户数
- 管理员数量
- 客户数量
- 活跃用户数

#### 3. 添加用户
点击"添加用户"按钮:
- 邮箱 (必填)
- 姓名 (必填)
- 密码 (必填,至少6位)
- 角色 (管理员/客户/访客)

#### 4. 查看用户详情
点击眼睛图标查看:
- 用户基本信息
- 订单数量
- 地址数量
- 注册时间
- 最后更新时间

#### 5. 编辑用户
点击编辑图标:
- 修改姓名
- 修改角色

#### 6. 删除用户
点击删除图标:
- 需要确认操作
- 删除后不可恢复

## ⚙️ 系统设置

### 访问路径
```
/admin/settings
```

### 功能说明

#### 1. 网站设置
配置网站基本信息:
- **网站名称**: 显示在浏览器标题栏
- **网站描述**: 用于 SEO
- **网站地址**: 完整的网站 URL
- **联系邮箱**: 客服邮箱
- **联系电话**: 客服电话
- **默认语言**: 中文/英文
- **默认货币**: CNY/USD/EUR

#### 2. 支付设置

**Stripe 支付**
- 启用/禁用开关
- Publishable Key 配置
- Secret Key 配置

**支付宝** (即将推出)
- 预留配置接口

**微信支付** (即将推出)
- 预留配置接口

#### 3. 邮件设置
配置 SMTP 邮件服务器:
- **SMTP 主机**: 如 smtp.gmail.com
- **SMTP 端口**: 通常是 587 或 465
- **SMTP 用户名**: 邮箱账号
- **SMTP 密码**: 邮箱密码或授权码
- **发件人邮箱**: 发送邮件的邮箱地址
- **发件人名称**: 显示的发件人名称
- **测试连接**: 测试邮件服务器配置

#### 4. 通知设置
管理系统通知偏好:
- **订单通知**: 新订单和状态变更通知
- **用户通知**: 新用户注册和活动通知
- **库存警报**: 低库存提醒
- **邮件通知**: 通过邮件接收通知
- **短信通知**: 通过短信接收重要通知

## 💡 使用技巧

### 1. 数据看板
- 定期查看数据趋势,及时发现异常
- 使用时间周期切换对比不同时段数据
- 关注订单状态分布,优化处理流程

### 2. 商品管理
- 使用批量操作提高效率
- 定期检查库存,及时补货
- 优化商品图片和描述,提高转化率

### 3. 订单管理
- 及时处理待处理订单
- 使用导出功能进行数据分析
- 批量更新状态提高处理效率

### 4. 用户管理
- 定期查看用户增长情况
- 关注活跃用户和订单数据
- 合理分配用户角色和权限

### 5. 系统设置
- 定期备份系统配置
- 测试邮件和支付配置是否正常
- 根据业务需求调整通知设置

## 🔒 安全提示

1. **密码安全**
   - 使用强密码
   - 定期更换密码
   - 不要共享管理员账号

2. **权限管理**
   - 谨慎分配管理员权限
   - 定期审查用户权限
   - 及时删除离职人员账号

3. **数据备份**
   - 定期导出重要数据
   - 保存系统配置备份
   - 建立数据恢复机制

4. **操作审计**
   - 关注系统操作日志
   - 定期检查异常操作
   - 建立操作规范
