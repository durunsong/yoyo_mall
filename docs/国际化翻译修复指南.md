# 国际化翻译修复指南

**日期**: 2025-10-28  
**状态**: 🔄 需要完善

## 问题总结

用户切换语言后，很多页面内容仍然显示中文，主要原因是：

1. **硬编码文本**: 很多组件中直接写中文字符串，没有使用 `t()` 翻译函数
2. **翻译key缺失**: 某些使用了 `t()` 但对应的翻译文件中没有该key
3. **翻译文件不完整**: 部分语言的翻译文件缺少某些命名空间或key

## 翻译系统概览

### 翻译Hook

项目中有两个主要的翻译Hook：

1. **`useTranslations(namespace)`** - 动态加载翻译文件
   ```typescript
   import { useTranslations } from '@/hooks/use-translations';
   const { t, locale, loading } = useTranslations('common');
   ```

2. **`useStaticTranslations(namespace)`** - 使用静态翻译（推荐）
   ```typescript
   import { useStaticTranslations } from '@/hooks/use-i18n';
   const { t, locale } = useStaticTranslations('common');
   ```

### 翻译文件位置

- **Public路径**: `/public/locales/{locale}/{namespace}.json`
- **支持语言**: `zh-CN`, `en-US`, `ja-JP`, `ko-KR`
- **命名空间**: `common`, `navigation`, `product`, `cart`, `auth`, `admin`, `error`, `account`

### 语言切换

使用 `LanguageSwitcher` 组件：
```typescript
import LanguageSwitcher from '@/components/ui/language-switcher';
<LanguageSwitcher mode="select" />
```

## 常见问题

### Q1: 翻译不生效怎么办？

**检查清单**:
1. ✅ 确认使用了 `useStaticTranslations` 或 `useTranslations`
2. ✅ 确认翻译key在对应的JSON文件中存在
3. ✅ 确认JSON文件格式正确（无语法错误）
4. ✅ 确认组件正确调用了 `t()` 函数
5. ✅ 刷新页面清除缓存

### Q2: 如何添加新的翻译命名空间？

1. 在 `/public/locales/{locale}/` 下创建新的JSON文件
2. 在组件中使用：`useStaticTranslations('your-namespace')`

### Q3: 如何处理动态内容？

使用参数替换：
```typescript
t('welcome', { name: userName })
// welcome: "Welcome, {{name}}!"
```

### Q4: 翻译文件太大怎么办？

使用命名空间拆分：
- `common.json` - 通用翻译
- `product.json` - 商品相关
- `cart.json` - 购物车相关
- `auth.json` - 认证相关
