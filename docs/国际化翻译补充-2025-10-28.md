## 数据库分类国际化（建议）

### 问题
图中的分类标签（"男装"、"女装"、"手机数码"等）来自数据库，目前只有中文。

### 解决方案1：在前端映射
```typescript
const categoryI18n: Record<string, Record<string, string>> = {
  'men-fashion': {
    'zh-CN': '男装',
    'en-US': 'Men Fashion',
  },
  'women-fashion': {
    'zh-CN': '女装',
    'en-US': 'Women Fashion',
  },
  // ... 更多分类
};

const getCategoryName = (slug: string, locale: string) => {
  return categoryI18n[slug]?.[locale] || slug;
};
```

### 解决方案2：数据库添加多语言字段
```prisma
model Category {
  id          String   @id @default(cuid())
  name        String   // 默认名称
  nameEn      String?  // 英文名称
  nameJa      String?  // 日文名称
  nameKo      String?  // 韩文名称
  // ...
}
```

### 解决方案3：使用JSON字段（推荐）
```prisma
model Category {
  id            String   @id @default(cuid())
  name          String   // 默认显示名称
  translations  Json?    // { "zh-CN": "男装", "en-US": "Men Fashion" }
  // ...
}
```
