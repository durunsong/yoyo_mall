## 🚀 快速启动

```bash
# 1. 安装依赖
pnpm install

# 2. 配置环境变量
cp .env.example .env.local
# 编辑 .env.local

# 3. 初始化数据库
pnpm db:generate
pnpm db:push
pnpm db:seed

# 4. 启动开发服务器
pnpm dev
```

## 📝 注意事项

1. **数据库迁移**：生产环境使用 `pnpm db:migrate` 而不是 `db:push`
2. **环境变量**：确保所有必需的环境变量都已配置
3. **支付测试**：使用 Stripe 测试密钥和测试卡号
4. **图片处理**：商品图片路径需要实际图片文件支持
