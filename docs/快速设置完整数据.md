## 🚨 常见问题

### Q1: 脚本执行失败？

**A**: 检查以下几点：
1. `.env.local` 文件是否存在并配置正确
2. 数据库是否正常运行
3. 网络连接是否正常
4. 是否安装了所有依赖

```bash
# 重新安装依赖
rm -rf node_modules
npm install

# 重新生成Prisma Client
npx prisma generate
```

### Q2: OSS图片不显示？

**A**: 
1. 检查OSS Bucket权限（需要公共读）
2. 检查图片URL是否正确
3. 检查浏览器控制台错误
4. 暂时使用占位图

### Q3: 订单数据不完整？

**A**: 
1. 确保所有依赖已安装
2. 检查 `prisma/seed-complete.ts` 是否有错误
3. 运行 `npm run db:reset:complete` 重新创建

### Q4: 如何清空数据重新开始？

**A**: 
```bash
# Windows PowerShell
npm run db:reset:complete

# macOS/Linux
npm run db:reset:complete
```
