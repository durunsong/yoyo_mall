## 🔧 常见操作

### 重置数据库

```bash
# 1. 重置数据库
pnpm db:push --force-reset

# 2. 重新运行种子
pnpm db:seed
```

### 清空数据库

```bash
# 使用 Prisma Studio
pnpm db:studio

# 或使用 SQL
# 连接到数据库后执行:
# TRUNCATE TABLE users, products, categories, brands CASCADE;
```

### 查看数据

```bash
# 打开 Prisma Studio
pnpm db:studio

# 访问: http://localhost:5555
```

## ⚠️ 注意事项

### 1. 数据重复

种子脚本使用 `upsert` 操作:
- 如果数据已存在(通过唯一字段判断),则更新
- 如果数据不存在,则创建

**示例**:
```typescript
await prisma.user.upsert({
  where: { email: 'admin@yoyomall.com' },
  update: {}, // 已存在时不更新
  create: {   // 不存在时创建
    // ... 创建数据
  },
});
```

### 2. 密码加密

所有用户密码都使用 bcrypt 加密:
```typescript
password: await bcrypt.hash('password123', 12)
```

### 3. 关联关系

确保先创建父级数据,再创建子级数据:
```
用户 → 用户档案
分类 → 子分类
品牌 → 商品
分类 → 商品
```

### 4. 数据库状态

运行种子前确保:
- ✅ 数据库已创建
- ✅ Prisma Schema 已同步
- ✅ 没有数据冲突

## 🐛 常见问题

### Q1: 运行种子失败

**错误**: `PrismaClientKnownRequestError: Unique constraint failed`

**解决方案**:
```bash
# 1. 检查数据是否已存在
pnpm db:studio

# 2. 清空相关表
# 3. 重新运行种子
pnpm db:seed
```

### Q2: 密码无法登录

**问题**: 使用种子数据的密码无法登录

**解决方案**:
- 确认使用正确的密码:
  - 管理员: `admin123456`
  - 测试用户: `password123`
- 检查 bcrypt 版本是否一致

### Q3: 关联数据缺失

**问题**: 商品没有分类或品牌

**解决方案**:
```bash
# 1. 检查种子脚本执行顺序
# 2. 确保先创建分类和品牌
# 3. 重新运行种子
pnpm db:seed
```

### Q4: 数据库连接失败

**错误**: `Can't reach database server`

**解决方案**:
```bash
# 1. 检查 .env 文件
DATABASE_URL="postgresql://user:password@localhost:5432/yoyo_mall"

# 2. 确认数据库服务运行
# 3. 测试连接
pnpm db:studio
```
