## 🐛 错误修复

### 修复1: API 400错误

**问题**: `GET /api/products?limit=8` 返回400错误

**原因**: Zod验证schema中 `.nullable()` 导致参数验证失败

**解决**: 
- 将 `.nullable()` 改为 `.optional()`
- 优化参数处理逻辑
- 只传递存在的URL参数

### 修复2: 无限循环请求

**问题**: 接口不断循环请求

**原因**: useEffect依赖项设置不当

**解决**:
- 使用 `useMemo` 稳定化query对象
- 直接依赖 `queryKey` 而非 `fetchProducts`
- 添加更好的错误处理

**详细文档**: `docs/错误修复记录.md`

## 💡 开发心得与最佳实践

### React Hooks 最佳实践

```typescript
// ✅ 正确: 使用 useMemo 稳定对象依赖
const queryKey = useMemo(() => JSON.stringify(query), [query]);
useEffect(() => {
  fetchData();
}, [queryKey]);

// ❌ 错误: 对象作为依赖会导致无限循环
useEffect(() => {
  fetchData();
}, [query]); // query 是对象
```

### Zod验证最佳实践

```typescript
// ✅ 正确: 使用 .optional()
sortBy: z.enum(['name', 'price']).optional().default('name')

// ❌ 错误: 使用 .nullable() 会保留 null
sortBy: z.enum(['name', 'price']).nullable().default('name')
```

### 表单状态管理

```typescript
// ✅ 推荐: 集中管理表单状态
const [formData, setFormData] = useState({
  firstName: '',
  lastName: '',
  email: '',
});

// 统一更新
onChange={(e) => setFormData({...formData, [name]: e.target.value})}
```
