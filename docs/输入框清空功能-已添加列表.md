## 🔍 使用方式

所有已添加的输入框都支持以下操作：

1. **自动显示**：输入内容后自动显示清空按钮
2. **一键清空**：点击 ❌ 按钮清空内容
3. **智能回调**：执行自定义清空逻辑（如重置筛选、刷新列表）
4. **视觉反馈**：悬停时按钮高亮

## 📝 代码示例

### 基础用法
```tsx
<Input
  clearable
  value={searchTerm}
  onChange={(e) => setSearchTerm(e.target.value)}
/>
```

### 带清空回调
```tsx
<Input
  clearable
  value={searchTerm}
  onChange={(e) => setSearchTerm(e.target.value)}
  onClear={() => {
    setSearchTerm('');
    // 其他清空逻辑
  }}
/>
```

## 🚀 后续扩展

如需在其他页面添加清空功能，只需：

1. 找到目标 `<Input>` 组件
2. 添加 `clearable` 属性
3. （可选）添加 `onClear` 回调
