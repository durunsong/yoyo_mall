# 后台全局搜索功能升级 - 2025-11-18

## 功能概述

升级了后台管理系统的全局搜索功能，现在不仅能搜索数据（商品、订单、用户），还能搜索后台的所有功能页面和设置项，并支持直接跳转到对应的页面或Tab。

## 主要特性

### 1. 多类型搜索支持

现在支持以下类型的搜索：

- **页面搜索**：所有后台功能页面（仪表板、商品管理、订单管理等）
- **设置搜索**：系统设置的各个Tab（网站设置、支付设置、邮件设置等）
- **商品搜索**：按商品名称、SKU、描述搜索
- **订单搜索**：按订单号、用户名搜索
- **用户搜索**：按用户名、邮箱搜索

### 2. 智能跳转

- 搜索"网站设置"，直接跳转到系统设置页面的网站设置Tab
- 搜索"支付设置"，直接跳转到系统设置页面的支付设置Tab
- 搜索"商品管理"，直接跳转到商品管理页面
- 搜索"订单"，会显示订单管理页面和所有相关订单数据

### 3. 优化的用户体验

- **彩色图标**：不同类型的搜索结果使用不同颜色的图标
- **彩色标签**：页面、设置、商品、订单、用户使用不同颜色的标签区分
- **父级标识**：设置项会显示其所属的父级页面（如"系统设置"）
- **键盘导航**：支持方向键上下选择，Enter键确认，ESC键关闭
- **结果统计**：底部显示找到的结果数量
- **高亮选中**：键盘选中的项目会有蓝色背景和边框高亮

## 使用示例

### 场景1：快速访问系统设置
1. 在搜索框输入"支付"或"payment"
2. 看到"支付设置"选项（橙色"设置"标签，显示"系统设置"父级）
3. 点击或按Enter，直接跳转到系统设置的支付设置Tab

### 场景2：查找特定商品
1. 在搜索框输入商品名称或SKU
2. 看到商品列表（蓝色"商品"标签，显示SKU和价格）
3. 点击查看商品详情

### 场景3：查看用户信息
1. 在搜索框输入用户名或邮箱
2. 看到用户列表（紫色"用户"标签，显示角色）
3. 点击查看用户详情

## 技术实现

### 后端 API
- 文件：`src/app/api/admin/search/route.ts`
- 功能：
  - 定义了完整的页面和设置配置（ADMIN_PAGES）
  - 实现了关键词匹配算法
  - 并行搜索数据库中的商品、订单、用户
  - 优先返回页面/设置搜索结果

### 前端组件
- 文件：`src/components/admin/admin-search.tsx`
- 功能：
  - 防抖搜索（300ms）
  - 智能图标匹配（根据标题和类型）
  - 键盘导航支持
  - 优化的视觉效果（彩色标签、高亮选中）
  - 响应式设计

## 搜索优先级

搜索结果按以下顺序显示：
1. 页面和设置项（优先显示）
2. 商品数据
3. 订单数据
4. 用户数据

## 快捷键

- **↑/↓** - 上下导航选择结果
- **Enter** - 确认选择并跳转
- **ESC** - 关闭搜索结果并清空搜索框

## 搜索提示

当搜索无结果时，会显示友好提示：
- "未找到相关结果"
- "试试搜索'商品'、'订单'或'系统设置'"

## 未来扩展

## 注意事项

1. 搜索需要管理员权限（ADMIN 或 SUPER_ADMIN）
2. 搜索结果会被限制数量（商品、订单、用户各最多5条）
3. 页面搜索结果无数量限制
4. 支持中英文混合搜索
5. 搜索不区分大小写
