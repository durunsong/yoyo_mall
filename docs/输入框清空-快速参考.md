# 输入框清空功能 - 快速参考卡

## ⚡ 快速开始

只需在任何 `<Input>` 组件上添加 `clearable` 属性：

```tsx
// 之前
<Input placeholder="搜索..." />

// 之后
<Input clearable placeholder="搜索..." />
```

## 📋 常用模式

### 1. 基础用法
```tsx
<Input clearable placeholder="搜索..." />
```

### 2. 受控组件
```tsx
<Input
  clearable
  value={value}
  onChange={(e) => setValue(e.target.value)}
/>
```

### 3. 带清空回调
```tsx
<Input
  clearable
  value={value}
  onChange={(e) => setValue(e.target.value)}
  onClear={() => {
    setValue('');
    // 其他清空逻辑
  }}
/>
```

### 4. 搜索框（带图标）
```tsx
<div className="relative">
  <Search className="absolute left-3 top-1/2 -translate-y-1/2 h-4 w-4 text-gray-400" />
  <Input
    clearable
    placeholder="搜索..."
    className="pl-10"
  />
</div>
```

## 🎯 推荐场景

| 场景 | 推荐使用 | 示例 |
|------|---------|------|
| 搜索框 | ✅ | 全局搜索、商品搜索 |
| 筛选器 | ✅ | 列表筛选、数据过滤 |
| 表单输入 | ✅ | 用户名、邮箱、地址 |
| 密码输入 | ❌ | 已有显示/隐藏功能 |
| 验证码 | ❌ | 输入简短不需要 |

## 🔧 快速改造现有代码

### 改造步骤：

1. **找到 Input 组件**
```tsx
<Input placeholder="搜索..." value={search} onChange={handleChange} />
```

2. **添加 clearable 属性**
```tsx
<Input clearable placeholder="搜索..." value={search} onChange={handleChange} />
```

3. **（可选）添加清空逻辑**
```tsx
<Input
  clearable
  placeholder="搜索..."
  value={search}
  onChange={handleChange}
  onClear={() => {
    setSearch('');
    setResults([]);
  }}
/>
```

## 📦 API

```tsx
interface InputProps {
  clearable?: boolean;        // 是否启用清空按钮
  onClear?: () => void;       // 清空回调函数
  // ... 其他标准 input 属性
}
```

## 🎨 清空按钮特性

- ✅ 只在有内容时显示
- ✅ 禁用状态自动隐藏
- ✅ 自动适配深色模式
- ✅ 不影响 Tab 键导航
- ✅ 有 hover 悬停效果

## 💡 最佳实践

### ✅ 推荐
```tsx
// 搜索框
<Input clearable placeholder="搜索商品..." />

// 带清空回调
<Input
  clearable
  onClear={() => {
    setValue('');
    resetFilters();
  }}
/>
```

### ❌ 不推荐
```tsx
// 密码框不需要
<Input type="password" clearable />

// 验证码不需要
<Input maxLength={6} clearable />
```
