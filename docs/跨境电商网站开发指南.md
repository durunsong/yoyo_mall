## 项目概述

### 项目简介

YOYO Mall 是一个现代化的跨境电商独立站解决方案，基于 Next.js 15 + React 19 + TypeScript 构建，提供完整的电商功能和优秀的用户体验。

### 核心特点

- ⚡ **现代技术栈**: Next.js 15 + React 19 + TypeScript 5.9
- 📱 **响应式设计**: 完美适配 PC、平板、手机
- 🌍 **国际化支持**: 多语言、多币种、多时区
- 💳 **支付集成**: Stripe 完整支付解决方案
- 🛒 **完整电商**: 商品、订单、库存、评价、心愿单
- 🔐 **安全可靠**: NextAuth 认证、数据加密、安全防护
- 🚀 **高性能**: 图片优化、代码分割、SEO 优化
- 📊 **数据分析**: 销售统计、用户行为分析

### 项目目标

- 为跨境电商提供开箱即用的独立站解决方案
- 提供优秀的购物体验和管理后台
- 支持快速部署和二次开发
- 遵循最佳实践和编码规范

## 开发环境搭建

### 系统要求

- **Node.js**: >= 18.0.0
- **pnpm**: >= 8.0.0 (推荐) 或 npm/yarn
- **PostgreSQL**: >= 14.0
- **操作系统**: Windows / macOS / Linux

### 安装步骤

#### 1. 克隆项目

```bash
git clone https://github.com/your-username/yoyo-mall.git
cd yoyo-mall
```

#### 2. 安装依赖

```bash
pnpm install
```

#### 3. 配置环境变量

```bash
cp .env.example .env.local
```

编辑 `.env.local`，配置必需变量：

```env
# 数据库
DATABASE_URL="postgresql://user:password@localhost:5432/yoyo_mall"

# NextAuth
NEXTAUTH_SECRET="your-super-secret-key"
NEXTAUTH_URL="http://localhost:3000"

# Stripe (测试环境)
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY="pk_test_..."
STRIPE_SECRET_KEY="sk_test_..."
```

#### 4. 初始化数据库

```bash
# 生成 Prisma Client
pnpm db:generate

# 推送数据库架构
pnpm db:push

# 填充测试数据
pnpm db:seed
```

#### 5. 启动开发服务器

```bash
pnpm dev
```

访问 http://localhost:3000

### 状态管理

#### Zustand Store

```typescript
// store/cart-store.ts
import create from 'zustand';

interface CartState {
  items: CartItem[];
  addItem: (item: CartItem) => void;
  removeItem: (id: string) => void;
}

export const useCartStore = create<CartState>((set) => ({
  items: [],
  addItem: (item) =>
    set((state) => ({
      items: [...state.items, item],
    })),
  removeItem: (id) =>
    set((state) => ({
      items: state.items.filter((item) => item.id !== id),
    })),
}));
```

## 后端开发指南

### API 路由开发

#### 标准结构

```typescript
// app/api/products/route.ts
import { NextRequest, NextResponse } from 'next/server';
import { prisma } from '@/lib/prisma';

export async function GET(request: NextRequest) {
  try {
    const products = await prisma.product.findMany();
    return NextResponse.json({ success: true, data: products });
  } catch (error) {
    return NextResponse.json(
      { success: false, error: '获取商品失败' },
      { status: 500 }
    );
  }
}
```

```typescript
});

export async function POST(request: NextRequest) {
  const body = await request.json();
  const validatedData = productSchema.parse(body);
  // 处理逻辑

```

#### Prisma 查询
