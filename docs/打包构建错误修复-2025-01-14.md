### 错误1: 缺少auth配置文件

**错误信息**:

```typescript
 * 在 NextAuth v5 中，使用 auth() 替代 getServerSession()

import { auth as nextAuth } from '@/app/api/auth/[...nextauth]/route';

 * 获取当前会话
 * 在 NextAuth v5 中，使用这个函数替代 getServerSession
 */

// 为了兼容性，也导出一个 getServerSession 别名
export const getServerSession = nextAuth;
```

### 错误2: formatDate函数缺失

**错误信息**:
```bash
Export formatDate doesn't exist in target module
  at ./src/app/admin/orders/page.tsx:58:1

The export formatDate was not found in module [project]/src/lib/utils.ts
```

**原因**: `src/app/admin/orders/page.tsx` 中导入了 `formatDate`，但该函数未在 `utils.ts` 中定义

**修复方案**: 在 `src/lib/utils.ts` 中添加 `formatDate` 函数

```typescript
/**
 * 格式化日期
 * @param date 日期字符串或Date对象
 * @param format 格式化选项，默认为 'datetime'
 * @returns 格式化后的日期字符串
 */
export function formatDate(
  date: string | Date,
  format: 'date' | 'datetime' | 'time' = 'datetime'
): string {
  const d = typeof date === 'string' ? new Date(date) : date;
  
  if (isNaN(d.getTime())) {
    return '-';
  }

  const year = d.getFullYear();
  const month = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');
  const hours = String(d.getHours()).padStart(2, '0');
  const minutes = String(d.getMinutes()).padStart(2, '0');
  const seconds = String(d.getSeconds()).padStart(2, '0');

  if (format === 'date') {
    return `${year}-${month}-${day}`;
  } else if (format === 'time') {
    return `${hours}:${minutes}:${seconds}`;
  } else {
    return `${year}-${month}-${day} ${hours}:${minutes}:${seconds}`;
  }
}
```

### 错误3: NextAuth v5 API变更

**错误信息**:
```bash
Export getServerSession doesn't exist in target module
  at ./src/app/api/user/addresses/[id]/route.ts:8:1
  at ./src/app/api/user/addresses/[id]/set-default/route.ts:7:1
  at ./src/app/api/user/addresses/route.ts:8:1
  at ./src/app/api/user/change-password/route.ts:7:1

The export getServerSession was not found in module 
[project]/node_modules/.pnpm/next-auth@5.0.0-beta.25_...
```

**原因**: NextAuth v5 移除了 `getServerSession`，改用新的 `auth()` 函数

**修复方案**: 更新所有API路由

**修改前**:
```typescript
import { getServerSession } from 'next-auth';
import { authOptions } from '@/lib/auth/auth-options';

const session = await getServerSession(authOptions);
```

**修改后**:
```typescript
import { auth } from '@/lib/auth';

const session = await auth();
```

**受影响文件**:
- ✅ `src/app/api/user/addresses/route.ts`
- ✅ `src/app/api/user/addresses/[id]/route.ts`
- ✅ `src/app/api/user/addresses/[id]/set-default/route.ts`
- ✅ `src/app/api/user/change-password/route.ts`

```typescript
  subsets: ['latin'],

  variable: '--font-sans',
```

```typescript
<body className={`${fontSans.variable} font-sans antialiased`}>
```

### 错误5: useSearchParams需要Suspense边界

**错误信息**:
```bash
⨯ useSearchParams() should be wrapped in a suspense boundary at page "/products". 
Read more: https://nextjs.org/docs/messages/missing-suspense-with-csr-bailout

Export encountered an error on /products/page: /products
```

**原因**: React 19 和 Next.js 15 要求使用 `useSearchParams` 的组件必须包裹在 Suspense 边界内

**修复方案**: 重构 `/products` 页面，添加 Suspense

**修改 `src/app/products/page.tsx`**:

```typescript
import { Suspense } from 'react';

// 将原组件重命名为内容组件
function ProductsPageContent() {
  const searchParams = useSearchParams(); // 使用 useSearchParams
  // ... 原有逻辑
}

// 导出包裹了Suspense的主组件
export default function ProductsPage() {
  return (
    <Suspense fallback={
      <div className="container mx-auto px-4 py-8">
        <div className="flex items-center justify-center min-h-[400px]">
          <div className="text-center">
            <div className="animate-spin rounded-full h-12 w-12 border-b-2 border-gray-900 mx-auto mb-4"></div>
            <p className="text-gray-600">Loading products...</p>
          </div>
        </div>
      </div>
    }>
      <ProductsPageContent />
    </Suspense>
  );
}
```

## 📚 经验教训

### 1. NextAuth版本升级注意事项

NextAuth v5 (beta) 有重大API变更:
- ❌ 移除: `getServerSession(authOptions)`
- ✅ 使用: `auth()` 函数
- 📝 配置导出: 从 `[...nextauth]/route.ts` 导出 `auth`

### 2. 网络环境考虑

在国内开发时:
- ❌ 避免依赖 Google Fonts、Google APIs 等被墙服务
- ✅ 使用本地字体或CDN托管的字体
- ✅ 考虑使用国内镜像源

### 3. React 19 新规范

- `useSearchParams`, `usePathname` 等hooks必须包裹Suspense
- 使用模式: 内容组件 + Suspense包裹组件
- 提供友好的Loading fallback

### 4. 构建工具选择

- Turbopack (--turbopack): 速度快，但可能有兼容性问题
- Webpack (默认): 稳定可靠，兼容性好
- 建议: 保留两种构建方式

### 5. 工具函数管理

- 统一在 `lib/utils.ts` 中定义工具函数
- 确保所有函数都正确导出
- 添加完整的JSDoc注释
