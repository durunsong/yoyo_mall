## 🐛 修复的问题

### 1. 商品价格显示错误 ✅

**错误信息:**
```
TypeError: D.price.toFixed is not a function
```

**问题原因:**
- Prisma 返回的 `price` 字段是 `Decimal` 类型
- JavaScript 的 `toFixed()` 方法只能用于 `Number` 类型

**修复方案:**
```typescript
// ❌ 错误写法
${product.price.toFixed(2)}

// ✅ 正确写法
${Number(product.price).toFixed(2)}
```

**修复位置:**
- `src/app/products/[id]/page.tsx` - 商品详情页
- `src/app/admin/products/page.tsx` - 后台商品管理
- 其他所有使用价格显示的地方

### 2. 头像上传后未更新显示 ✅

**问题描述:**
1. 用户上传头像后,导航栏头像不更新
2. 需要刷新页面才能看到新头像
3. Session 中的头像字段未正确同步

**根本原因:**
- NextAuth 使用 `image` 字段,但数据库使用 `avatar` 字段
- Session callbacks 没有正确处理字段映射
- Avatar 组件没有强制刷新机制

**修复方案:**

#### A. NextAuth 配置修复
```typescript
// src/app/api/auth/[...nextauth]/route.ts

callbacks: {
  async jwt({ token, user, account, trigger, session }: any) {
    if (user) {
      token.avatar = user.image || user.avatar; // 支持两种字段名
    }

    // Session update 时更新头像
    if (trigger === 'update' && session?.user) {
      if ((session.user as any).avatar) {
        token.avatar = (session.user as any).avatar;
      }
    }
    
    return token;
  },
  
  async session({ session, token }: any) {
    if (token.avatar) {
      // 同时设置两个字段,确保兼容性
      (session.user as any).avatar = token.avatar;
      (session.user as any).image = token.avatar;
    }
    return session;
  },
}
```

#### B. 头像上传 API 修复
```typescript
// src/app/api/user/avatar/route.ts

// 上传成功后更新数据库
await prisma.user.update({
  where: { id: session.user.id },
  data: { avatar: uploadResult.url },
});

return NextResponse.json({
  success: true,
  avatarUrl: uploadResult.url, // 返回新头像URL
});
```

#### C. 前端组件修复
```typescript
// src/app/account/settings/page.tsx

const handleAvatarUpload = async (e: React.ChangeEvent<HTMLInputElement>) => {
  // ... 上传逻辑 ...
  
  if (data.success) {
    setProfileForm({ ...profileForm, avatar: data.avatarUrl });
    // 关键: 更新 session
    await updateSession({ avatar: data.avatarUrl });
    toast.success('头像上传成功');
  }
};
```

#### D. 导航栏头像显示修复
```typescript
// src/components/layout/shadcn-header.tsx

<Avatar className="mr-2 h-6 w-6">
  <AvatarImage
    key={(session.user as any).avatar || Date.now()} // 强制刷新
    src={(session.user as any).avatar || '/avatars/default-avatar.svg'}
    alt={session.user.name || 'User Avatar'}
  />
  <AvatarFallback>{(session.user?.name || 'U').slice(0, 1)}</AvatarFallback>
</Avatar>
```

**关键技巧:**
- 使用 `key` 属性强制 React 重新渲染组件
- 使用 `updateSession()` 触发 NextAuth session 更新
- 同时支持 `avatar` 和 `image` 字段名

- ✅ 自动压缩(85%质量)
- ✅ OSS 存储
- ✅ 进度显示

**使用示例:**
```typescript
import { ProductImageUpload } from '@/components/upload/product-image-upload';

function ProductForm() {
```

```typescript

  folder?: string;         // OSS文件夹,默认'products'
}
```

## 🔧 开发指南

### 后台商品管理集成图片上传

#### 1. 安装依赖(已完成)
```bash
# 已安装
npm install sharp uuid ali-oss
```

#### 2. 在商品表单中使用
```typescript
// src/app/admin/products/page.tsx (示例)

import { ProductImageUpload } from '@/components/upload/product-image-upload';

function ProductForm() {
  const [formData, setFormData] = useState({
    name: '',
    price: 0,
    images: [] as string[],
    // ...
  });

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    
    // 创建商品
    await fetch('/api/products', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        ...formData,
        // images 已经是 OSS URL 数组
      }),
    });
  };

  return (
    <form onSubmit={handleSubmit}>
      {/* 其他字段 */}
      
      <div>
        <label>商品图片</label>
        <ProductImageUpload
          value={formData.images}
          onChange={(images) => setFormData({ ...formData, images })}
          maxImages={10}
          folder="products"
        />
      </div>

      <button type="submit">保存商品</button>
    </form>
  );
}
```

#### 3. API 端点

**图片上传:**
- `POST /api/upload/image`
- 支持单文件和多文件
- 自动上传到 OSS
- 返回 OSS URL

**图片删除:**
- `POST /api/upload/delete`
- 删除 OSS 文件
- 传入 URL 或 key

## 🚀 部署注意事项

### 1. 环境变量检查

确保以下环境变量已配置:
```env
# 阿里云 OSS(必需)
OSS_ACCESS_KEY_ID=your_access_key_id
OSS_ACCESS_KEY_SECRET=your_access_key_secret
OSS_REGION=oss-rg-china-mainland
OSS_BUCKET=your_bucket_name
OSS_FOLDER=yoyo_mall
BASE_OSS_URL=https://your-bucket.oss-region.aliyuncs.com
```

### 2. OSS Bucket 配置

1. **跨域配置(CORS)**
```json
{
  "AllowedOrigin": ["*"],
  "AllowedMethod": ["GET", "POST", "PUT", "DELETE"],
  "AllowedHeader": ["*"],
  "ExposeHeader": ["ETag"],
  "MaxAgeSeconds": 3600
}
```

2. **访问权限**
- 设置为 **公共读**
- 或配置 **CDN加速域名**

3. **生命周期规则(可选)**
- `temp/` 文件夹: 7天自动删除
- 其他文件夹: 永久保存

### 3. Next.js 配置

```javascript
// next.config.mjs
const nextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 'next-static-oss.oss-rg-china-mainland.aliyuncs.com',
        pathname: '/yoyo_mall/**',
      },
    ],
  },
};
```
