# Yobuy 单店 SaaS 化独立站设计

## 目标

将现有 Yobuy 跨境电商项目升级为可运营的单品牌独立站：品牌、首页内容、商品、市场、币种、配送和运营配置由后台控制；前台关键购物链路具有连续、可恢复、移动端优先的交互。

## 非目标

- 不实现多租户、商户隔离、域名托管或租户计费。
- 不替换现有 Prisma、NextAuth、Stripe、OSS 和邮件供应商。
- 不在本阶段新增第三方 UI 或状态管理依赖。

## 方案

升级到 Next 16.3.x，并要求 Node >=20.9。保留 App Router 和现有 Prisma 数据模型。前台布局统一由 `ConditionalLayout` 承载，导航提供可访问的搜索、账户、心愿单、购物车抽屉和移动端快捷入口；购物车继续由 Zustand 管理，并通过现有 `/api/cart` 同步服务端。

首页和商品流采用真实数据优先、可配置内容降级；商品卡片支持键盘可达的收藏和加购，所有异步操作有 pending、成功、失败和重试状态。结算页在地址、库存、优惠券或支付失败时保留用户输入并给出恢复入口。

## 验收标准

1. `package.json` 与锁文件使用 Next 16.3.x、Node 20+ 运行要求，`next build` 不依赖忽略 TypeScript/ESLint 错误。
2. 桌面端与移动端均可完成：搜索商品 -> 查看详情 -> 加购 -> 修改数量 -> 应用优惠券 -> 进入结算。
3. 导航、购物车数量、心愿单数量和登录状态在路由切换后保持一致；异步操作不会重复提交。
4. 空数据、网络失败、未登录、库存不足和支付失败均有可操作反馈。
5. 类型检查、Lint、单元测试和生产构建均运行并记录结果。
