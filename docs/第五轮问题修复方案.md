## 🔧 修复方案

### 问题1: Image组件缺少sizes属性

**位置**: `src/app/account/wishlist/page.tsx`

**原因**: 使用了`fill`属性的Image没有提供`sizes`

**修复**:
```typescript
// 修改前
<Image
  src={item.product.images[0].url}
  alt={item.product.name}
  width={300}
  height={300}
  className="..."
/>

// 修改后
<Image
  src={item.product.images[0].url}
  alt={item.product.name}
  width={300}
  height={300}
  sizes="(max-width: 640px) 100vw, (max-width: 1024px) 50vw, 33vw"
  className="..."
/>
```

### 问题2: 心愿单角标不显示

**原因**: 
- 前端使用Zustand本地store
- 后端使用数据库存储
- 两者数据不同步

**解决方案**: 
1. 添加心愿单同步组件（类似购物车同步）
2. 登录后从API获取心愿单并更新本地store
3. 添加/删除时同时更新本地和服务端

### 问题3: 购物车与用户关联

**原因**: 
- 当前购物车只存在localStorage
- 已有CartSync组件但可能未正确触发

**解决方案**:
1. 检查并优化CartSync组件
2. 登录后立即同步本地购物车到服务端
3. 刷新时从服务端恢复购物车数据

### 问题4: 消息标记已读不持久化

**原因**:
- 当前使用模拟数据（useState）
- 标记已读只在内存中，刷新后重置

**解决方案**:
1. 将通知数据持久化到localStorage
2. 或连接真实API
3. 标记已读时保存到持久化存储

## 📝 实现细节

### 1. 添加心愿单同步组件

创建 `src/components/wishlist/wishlist-sync.tsx`:

```typescript
'use client';

import { useEffect } from 'react';
import { useSession } from 'next-auth/react';
import { useWishlistStore } from '@/store/wishlist-store';

export function WishlistSync() {
  const { data: session } = useSession();
  const { items, setItems } = useWishlistStore();

  useEffect(() => {
    if (!session?.user) return;

    // 同步本地心愿单到服务端
    const syncWishlist = async () => {
      try {
        // 1. 获取服务端心愿单
        const response = await fetch('/api/wishlist');
        const data = await response.json();

        if (data.success) {
          // 2. 更新本地store
          const serverItems = data.data.map((item: any) => ({
            id: item.id,
            productId: item.product.id,
            name: item.product.name,
            price: item.product.price,
            image: item.product.images[0]?.url || '',
            addedAt: new Date(item.createdAt),
          }));
          
          setItems(serverItems);
        }
      } catch (error) {
        console.error('心愿单同步失败:', error);
      }
    };

    syncWishlist();
  }, [session, setItems]);

  return null;
}
```

### 2. 优化购物车同步

更新 `src/components/cart/cart-sync.tsx`:

```typescript
// 添加从服务端恢复购物车的功能
const restoreCartFromServer = async () => {
  if (!session?.user) return;

  try {
    const response = await fetch('/api/cart');
    const data = await response.json();

    if (data.success) {
      // 清空本地购物车
      clearCart();
      
      // 从服务端恢复
      data.data.forEach((item: any) => {
        addItem({
          productId: item.productId,
          name: item.product.name,
          price: item.product.price,
          image: item.product.images[0]?.url || '',
          quantity: item.quantity,
          variantId: item.variantId,
        });
      });
    }
  } catch (error) {
    console.error('购物车恢复失败:', error);
  }
};

// 登录后立即恢复
useEffect(() => {
  if (session?.user) {
    restoreCartFromServer();
  }
}, [session?.user?.id]);
```

### 3. 持久化通知状态

更新 `src/components/layout/user-notifications.tsx`:

```typescript
// 使用localStorage持久化通知状态
const [notifications, setNotifications] = useState<Notification[]>(() => {
  if (typeof window === 'undefined') return [];
  const saved = localStorage.getItem('notifications');
  return saved ? JSON.parse(saved) : [];
});

// 保存到localStorage
useEffect(() => {
  localStorage.setItem('notifications', JSON.stringify(notifications));
}, [notifications]);

// 标记已读时保存
const markAsRead = (id: string) => {
  setNotifications(prev => {
    const updated = prev.map(n => (n.id === id ? { ...n, read: true } : n));
    localStorage.setItem('notifications', JSON.stringify(updated));
    return updated;
  });
};
```
