### ❌ 问题2: API无限循环请求

**错误现象**:
```
http://localhost:3000/api/products?limit=8 一直在请求
```

**报错位置**: `src/hooks/use-products.ts`

**原因分析**:

在 `useProducts` Hook 中存在无限循环问题:

```typescript
// 问题代码
export function useProducts(query: ProductQuery = {}) {
  const fetchProducts = useCallback(async (searchQuery: ProductQuery = {}) => {
    // ...
  }, [query]); // ❌ query是对象，每次都是新引用

  useEffect(() => {
    fetchProducts();
  }, [fetchProducts]); // ❌ fetchProducts每次都重新创建
}
```

**触发流程**:
1. 组件渲染，传入 `query` 对象
2. `query` 对象每次都是新的引用（即使值相同）
3. `useCallback` 依赖 `query` 变化，重新创建 `fetchProducts`
4. `useEffect` 依赖 `fetchProducts` 变化，触发请求
5. 请求完成，组件可能重新渲染，回到步骤1 → **无限循环**

**解决方案**:

使用 `JSON.stringify` 将对象转换为稳定的字符串key:

```typescript
// 修复后 ✅
export function useProducts(query: ProductQuery = {}) {
  // 将query转换为稳定的字符串key
  const queryKey = JSON.stringify(query);

  const fetchProducts = useCallback(async (searchQuery: ProductQuery = {}) => {
    const mergedQuery = { ...JSON.parse(queryKey), ...searchQuery };
    // ...
  }, [queryKey]); // ✅ 使用字符串依赖，引用稳定

  useEffect(() => {
    fetchProducts();
  }, [fetchProducts]);
}
```

**修复文件**:
- `src/hooks/use-products.ts`

**影响范围**:
- ✅ 首页商品加载
- ✅ 商品列表页
- ✅ 所有使用 useProducts 的页面

### ❌ 问题: 商品API 400错误

**错误信息**:
```
GET http://localhost:3000/api/products?limit=8 400 (Bad Request)
获取商品列表失败
```

**报错位置**: `use-products.ts:141`

**原因分析**:

在 `src/app/api/products/route.ts` 中,Zod验证schema存在问题:

```typescript
// 问题代码
sortBy: z.enum(['name', 'price', 'createdAt']).nullable().default('createdAt'),
sortOrder: z.enum(['asc', 'desc']).nullable().default('desc'),
```

当URL参数不包含 `sortBy` 和 `sortOrder` 时，`searchParams.get()` 返回 `null`,而 `.nullable()` 会保留这个 `null` 值,导致 enum 验证失败。

**解决方案**:

1. **修改验证schema**:
   ```typescript
   // 修复后
   sortBy: z.enum(['name', 'price', 'createdAt']).optional().default('createdAt'),
   sortOrder: z.enum(['asc', 'desc']).optional().default('desc'),
   ```

2. **优化参数处理**:
   ```typescript
   // 只包含存在的参数
   const rawQuery: any = {};
   
   if (searchParams.has('page')) rawQuery.page = searchParams.get('page');
   if (searchParams.has('limit')) rawQuery.limit = searchParams.get('limit');
   // ... 其他参数
   
   const query = productQuerySchema.parse(rawQuery);
   ```

**修复文件**:
- `src/app/api/products/route.ts`

**测试验证**:
```bash

curl http://localhost:3000/api/products?limit=8

# 带完整参数也应该正常
curl "http://localhost:3000/api/products?limit=8&sortBy=price&sortOrder=asc"
```

**影响范围**:

## 技术细节

### Zod验证最佳实践

1. **使用 `.optional()` 而不是 `.nullable()`**
   ```typescript
   // ❌ 错误 - 会保留 null 值
   field: z.string().nullable().default('default')
   
   // ✅ 正确 - null/undefined 都会使用默认值
   field: z.string().optional().default('default')
   ```

2. **URL参数处理**
   ```typescript
   // ❌ 错误 - 所有参数都传递,包括 null
   const query = schema.parse({
     param1: searchParams.get('param1'),  // 可能是 null
     param2: searchParams.get('param2'),  // 可能是 null
   });
   
   // ✅ 正确 - 只传递存在的参数
   const rawQuery: any = {};
   if (searchParams.has('param1')) {
     rawQuery.param1 = searchParams.get('param1');
   }
   const query = schema.parse(rawQuery);
   ```

3. **coerce使用场景**
   ```typescript
   // 数字类型使用 coerce 自动转换字符串
   page: z.coerce.number().min(1).default(1)
   
   // 字符串类型不需要 coerce
   search: z.string().optional()
   ```

### ❌ 问题: useProducts Hook 无限循环请求

**错误现象**:
```
接口不断循环请求:
GET http://localhost:3000/api/products?limit=8
GET http://localhost:3000/api/products?limit=8
GET http://localhost:3000/api/products?limit=8
...
```

**报错位置**: `src/hooks/use-products.ts`

**原因分析**:

useEffect 的依赖项设置不当导致无限循环:

```typescript
// 问题代码
const fetchProducts = useCallback(async () => {
  // ...
}, [query]); // query 是对象,每次渲染都是新引用

useEffect(() => {
  fetchProducts();
}, [fetchProducts]); // fetchProducts 每次都变化,导致无限循环
```

**解决方案**:

1. **使用 useMemo 稳定化 query**:
   ```typescript
   // 将对象转为稳定的字符串key
   const queryKey = useMemo(() => JSON.stringify(query), [query]);
   ```

2. **修改 useEffect 依赖**:
   ```typescript
   useEffect(() => {
     fetchProducts();
   }, [queryKey]); // 直接依赖稳定的 queryKey
   ```

3. **添加错误处理**:
   ```typescript
   if (!response.ok) {
     throw new Error(`HTTP error! status: ${response.status}`);
   }
   ```

**修复文件**:
- `src/hooks/use-products.ts`

**影响范围**:
- ✅ 首页 (不再无限请求)
- ✅ 商品列表页
- ✅ 所有使用 useProducts 的页面

### React Hooks 最佳实践

1. **对象类型的依赖项处理**
   ```typescript
   // ❌ 错误 - 对象每次都是新引用
   useEffect(() => {
     fetchData(config);
   }, [config]); // config 是对象
   
   // ✅ 正确 - 使用稳定的序列化值
   const configKey = useMemo(() => JSON.stringify(config), [config]);
   useEffect(() => {
     fetchData(JSON.parse(configKey));
   }, [configKey]);
   ```

2. **useCallback 依赖链**
   ```typescript
   // ❌ 可能导致循环
   const fn = useCallback(() => {}, [dep]);
   useEffect(() => { fn() }, [fn]);
   
   // ✅ 直接依赖原始值
   const fn = useCallback(() => {}, [dep]);
   useEffect(() => { fn() }, [dep]);
   ```

3. **性能优化建议**
   - 使用 `useMemo` 缓存计算结果
   - 使用 `useCallback` 缓存函数引用
   - 避免在依赖数组中使用对象或数组字面量
