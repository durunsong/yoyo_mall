## 🖼️ 图片优化

### 1. Next.js Image 组件配置

**配置文件**: `next.config.mjs`

```javascript
images: {
  // 支持的外部图片域名
  remotePatterns: [
    { protocol: 'https', hostname: 'images.unsplash.com' },
    { protocol: 'https', hostname: '**.cloudinary.com' },
  ],
  
  // 现代图片格式
  formats: ['image/avif', 'image/webp'],
  
  // 响应式尺寸
  deviceSizes: [640, 750, 828, 1080, 1200, 1920, 2048, 3840],
  imageSizes: [16, 32, 48, 64, 96, 128, 256, 384],
  
  // 缓存时间
  minimumCacheTTL: 60,
}
```

### 2. 图片优化效果

- ✅ 自动格式转换 (AVIF/WebP)
- ✅ 自动响应式处理
- ✅ 懒加载支持
- ✅ 模糊占位符
- ✅ CDN 缓存

### 3. 使用示例

```tsx
import Image from 'next/image';

// 推荐用法
<Image
  src="/product.jpg"
  alt="商品图片"
  width={500}
  height={500}
  priority={false} // 首屏图片设为 true
  placeholder="blur"
  blurDataURL="data:image/..." // 可选
/>
```

## 🚀 性能监控

### 1. Core Web Vitals

监控的关键指标:
- **LCP** (Largest Contentful Paint): < 2.5s
- **FID** (First Input Delay): < 100ms
- **CLS** (Cumulative Layout Shift): < 0.1
- **FCP** (First Contentful Paint): < 1.8s
- **TTFB** (Time to First Byte): < 600ms

### 2. 性能监控工具

**使用方法**:
```typescript
import { reportWebVitals, measureAsyncPerformance } from '@/lib/performance';

// 监控 API 性能
const data = await measureAsyncPerformance('fetchProducts', async () => {
  return await fetch('/api/products');
});
```

### 3. API 性能监控

```typescript
import { APIPerformanceMonitor } from '@/lib/performance';

APIPerformanceMonitor.start('/api/products');
const response = await fetch('/api/products');
APIPerformanceMonitor.end('/api/products');
```

## 🔒 安全和缓存优化

### 1. HTTP Headers

**Security Headers**:
```javascript
{
  'X-DNS-Prefetch-Control': 'on',
  'Strict-Transport-Security': 'max-age=63072000',
  'X-Frame-Options': 'SAMEORIGIN',
  'X-Content-Type-Options': 'nosniff',
  'X-XSS-Protection': '1; mode=block',
}
```

### 2. 缓存策略

**静态资源**:
```javascript
{
  source: '/static/:path*',
  headers: [{
    key: 'Cache-Control',
    value: 'public, max-age=31536000, immutable',
  }],
}
```

**API 响应**: 
- 使用 `stale-while-revalidate`
- 配置合适的 `max-age`

## 💾 数据库优化

### 1. 查询优化

**并行查询**:
```typescript
const [products, total, categories] = await Promise.all([
  prisma.product.findMany({ ... }),
  prisma.product.count({ ... }),
  prisma.category.findMany({ ... }),
]);
```

**选择性查询**:
```typescript
// 只查询需要的字段
const products = await prisma.product.findMany({
  select: {
    id: true,
    name: true,
    price: true,
    // 不查询 description 等大字段
  },
});
```

### 2. 索引优化

```prisma
model Product {
  id    String @id
  slug  String @unique // 索引
  sku   String @unique // 索引
  
  @@index([categoryId]) // 复合索引
  @@index([status, createdAt])
}
```

### DO ✅

2. 避免过度的客户端渲染
3. 不要忽略移动端性能
4. 避免不必要的重渲染
5. 不要忽略错误处理
6. 避免阻塞渲染的脚本
