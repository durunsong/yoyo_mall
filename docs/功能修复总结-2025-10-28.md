**根本原因**: `ProductSearch` 组件没有实现真正的跳转逻辑

**修复方案**:
```typescript
// src/components/products/product-search.tsx
import { useRouter } from 'next/navigation';

const handleSearch = () => {
  // 默认行为：跳转到商品列表页并传递搜索关键词
  if (searchValue.trim()) {
    router.push(`/products?search=${encodeURIComponent(searchValue.trim())}`);
  } else {
    router.push('/products');
  }
};
```

### 3. 收藏功能 ✅

**问题**: ProductCard 组件中的收藏按钮点击无效

**根本原因**: 收藏按钮没有绑定任何事件处理函数

**修复方案**:

#### 3.1 修改 ProductCard 组件
```typescript
// src/components/products/product-card.tsx
interface ProductCardProps {
  // ... 其他属性
  onAddToWishlist?: (productId: string) => void; // 新增
}

// 处理收藏
const handleWishlist = (e: React.MouseEvent) => {
  e.preventDefault(); // 阻止Link导航
  e.stopPropagation();
  if (onAddToWishlist) {
    onAddToWishlist(id);
  }
};

<Button onClick={handleWishlist}>
  <Heart className="h-4 w-4" />
</Button>
```

#### 3.2 在所有使用 ProductCard 的页面添加收藏处理

**修改文件**:
- ✅ `src/app/[locale]/page.tsx` (首页)
- ✅ `src/app/products/page.tsx` (商品列表)
- ✅ `src/app/deals/page.tsx` (优惠页面)

**实现逻辑**:
```typescript
const handleAddToWishlist = async (productId: string) => {
  try {
    const response = await fetch('/api/wishlist', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ productId }),
    });
    
    const data = await response.json();
    
    if (data.success) {
      toast.success('已添加到心愿单');
    } else {
      toast.error(data.message || '添加失败');
    }
  } catch (error) {
    toast.error('添加失败，请重试');
  }
};
```

**测试方法**:
1. 在商品卡片上悬停
2. 点击右上角的爱心图标
3. 应该显示 "已添加到心愿单" 提示
4. 访问 `/account/wishlist` 查看收藏的商品
