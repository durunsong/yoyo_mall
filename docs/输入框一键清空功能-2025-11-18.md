# 输入框一键清空功能 - 2025-11-18

## 功能概述

为项目中所有输入框添加了可选的一键清空功能，通过在输入框右侧显示 ❌ 按钮，用户可以快速清空输入内容。

## 特性

- ✅ **可选启用**：通过 `clearable` 属性控制，不影响现有代码
- ✅ **智能显示**：只在输入框有内容时显示清空按钮
- ✅ **禁用状态**：禁用的输入框不显示清空按钮
- ✅ **完全兼容**：支持受控和非受控组件模式
- ✅ **无障碍支持**：包含 `aria-label` 属性
- ✅ **响应式设计**：适配深色模式
- ✅ **优雅交互**：悬停效果和过渡动画

## 使用方法

### 基础用法

只需要添加 `clearable` 属性即可：

```tsx
<Input 
  clearable 
  placeholder="输入内容..." 
/>
```

### 受控组件模式

```tsx
const [value, setValue] = useState('');

<Input
  clearable
  value={value}
  onChange={(e) => setValue(e.target.value)}
  placeholder="搜索商品..."
/>
```

### 带清空回调

当用户点击清空按钮时执行自定义逻辑：

```tsx
<Input
  clearable
  value={searchQuery}
  onChange={(e) => setSearchQuery(e.target.value)}
  onClear={() => {
    console.log('输入框已清空');
    // 执行其他操作，如重置搜索结果
    setSearchResults([]);
  }}
  placeholder="搜索..."
/>
```

## API 参考

### Input Props

| 属性 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `clearable` | `boolean` | `false` | 是否启用清空按钮 |
| `onClear` | `() => void` | - | 点击清空按钮时的回调函数 |
| 其他 | `React.ComponentProps<'input'>` | - | 所有标准 HTML input 属性 |

### 清空按钮行为

1. **显示条件**：
   - ✅ `clearable={true}` 
   - ✅ 输入框有内容
   - ✅ 输入框未禁用

2. **点击清空按钮时**：
   - 清空输入框内容
   - 调用 `onClear` 回调（如果提供）
   - 触发 `onChange` 事件（值为空字符串）

3. **样式特点**：
   - 灰色 X 图标
   - 悬停时背景变亮
   - 支持深色模式
   - 不影响 Tab 键导航（`tabIndex={-1}`）

## 向后兼容

这个功能是完全向后兼容的：

- ✅ 现有的所有 Input 组件继续正常工作
- ✅ 不添加 `clearable` 属性时，行为与之前完全一样
- ✅ 不会影响任何现有功能

### 技术实现

1. **状态管理**：使用内部状态 `internalValue` 跟踪输入值
2. **同步机制**：通过 `useEffect` 同步外部 `value` 到内部状态
3. **事件处理**：清空时触发合成的 `onChange` 事件，确保表单状态同步
4. **布局方案**：使用相对定位的 wrapper div 和绝对定位的清空按钮
5. **样式调整**：有清空按钮时，输入框右侧 padding 自动增加（`pr-9`）

```tsx

const [searchTerm, setSearchTerm] = useState('');
const [debouncedSearch] = useDebounce(searchTerm, 300);
```
