## 问题描述

用户反馈加购支付流程存在严重问题：
- **问题1**: 点击"加入购物车"按钮无任何响应
- **问题2**: 购物车页面无法正常显示商品信息
- **问题3**: 结账页面数据结构不匹配

## 根本原因分析

### 1. 商品卡片 `addToCart` 调用错误

**位置**: `src/app/products/[id]/page.tsx`

**问题**:
```typescript
// ❌ 错误：只传递了 productId 和 quantity
await addItem(product.id, quantity);
```

**原因**: `useCartStore` 的 `addItem` 方法需要完整的 `CartItem` 对象：
```typescript
interface CartItem {
  id: string;          // ❌ 缺失
  productId: string;   // ✅ 传递了
  variantId?: string;  
  quantity: number;    // ✅ 传递了
  price: number;       // ❌ 缺失
  name: string;        // ❌ 缺失
  image: string;       // ❌ 缺失
  attributes?: Array<{ name: string; value: string }>;
}
```

**修复**:
```typescript
// ✅ 正确：传递完整的购物车项目对象
addItem({
  productId: product.id,
  quantity: quantity,
  price: product.price,
  name: product.name,
  image: product.images[0]?.url || '/placeholder.png',
});
```

### 2. 首页和商品列表页缺少 `onAddToCart` 回调

**位置**: 
- `src/app/[locale]/page.tsx` (首页)
- `src/app/products/page.tsx` (商品列表页)

**问题**: `ProductCard` 组件被调用时未传递 `onAddToCart` 属性
```typescript
// ❌ 缺少回调
<ProductCard key={product.id} product={product} />
```

**修复**: 添加统一的加购处理函数
```typescript
const { addItem } = useCartStore();

const handleAddToCart = (product: { id: string; name: string; price: number; image?: string }) => {
  addItem({
    productId: product.id,
    quantity: 1,
    price: product.price,
    name: product.name,
    image: product.image || '/placeholder.png',
  });
  toast.success('已添加到购物车');
};

// ✅ 传递回调
<ProductCard 
  key={product.id} 
  product={product} 
  onAddToCart={handleAddToCart}
/>
```

### 3. `ProductCard` 组件回调签名不匹配

**位置**: `src/components/products/product-card.tsx`

**问题**: 回调只传递 `productId` 字符串
```typescript
// ❌ 只传递 ID
onAddToCart?: (productId: string) => void;
onClick={() => onAddToCart?.(id)}
```

**修复**: 传递完整的商品信息对象
```typescript
// ✅ 传递完整信息
onAddToCart?: (product: {
  id: string;
  name: string;
  price: number;
  image?: string;
}) => void;

onClick={() => onAddToCart?.({ id, name, price, image })}
```

### 4. 购物车页面数据结构不匹配

**位置**: `src/app/cart/page.tsx`

**问题**: 期望的数据结构 vs 实际数据结构
```typescript
// ❌ 期望的结构（嵌套 product 对象）
item.product.name
item.product.price
item.product.images

// ✅ 实际的结构（扁平化）
item.name
item.price
item.image
```

**原因**: 购物车使用 Zustand 本地状态管理，`CartItem` 类型是扁平化的简单对象，不包含嵌套的 `product` 对象。

**修复**: 
1. 移除对 `fetchCart` 的依赖（本地 store 不需要）
2. 修改所有引用为扁平化结构
3. 修改价格计算逻辑

```typescript
// ❌ 错误
const { items, loading, fetchCart } = useCartStore();
const subtotal = items.reduce(
  (sum, item) => sum + Number(item.product.price) * item.quantity,
  0
);

// ✅ 正确
const { items } = useCartStore();
const subtotal = items.reduce(
  (sum, item) => sum + item.price * item.quantity,
  0
);
```

### 5. 结账页面相同问题

**位置**: `src/app/(shop)/checkout/page.tsx`

**修复**: 与购物车页面相同的修复策略

## 技术要点总结

### 1. Zustand 状态管理
```typescript
// store 定义
interface CartState {
  items: CartItem[];
  addItem: (item: Omit<CartItem, 'id'>) => void;
  // ...
}

// 使用方式
const { items, addItem } = useCartStore();
addItem({ productId, quantity, price, name, image });
```

### 2. 购物车项目类型
```typescript
interface CartItem {
  id: string;          // 购物车项ID（自动生成）
  productId: string;   // 商品ID
  variantId?: string;  // 可选：商品变体ID
  quantity: number;    // 数量
  price: number;       // 单价
  name: string;        // 商品名称
  image: string;       // 商品图片URL
  attributes?: Array<{ name: string; value: string }>; // 可选：商品属性
}
```

### 3. 组件通信模式
```typescript
// 父组件（页面）
const handleAddToCart = (product) => {
  addItem({ ...product, quantity: 1 });
  toast.success('已添加到购物车');
};

// 子组件（ProductCard）
<Button onClick={() => onAddToCart?.({ id, name, price, image })}>
  加入购物车
</Button>
```
