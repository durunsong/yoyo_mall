### 问题2: 心愿单角标不显示 ✅

**根因**: 前端Zustand store和后端数据库未同步

**解决方案**: 创建心愿单同步组件

**新增文件**: `src/components/wishlist/wishlist-sync.tsx`

**核心逻辑**:
```typescript
// 登录后从服务端同步心愿单
useEffect(() => {
  if (status === 'authenticated' && session?.user && !synced) {
    const syncWishlistFromServer = async () => {
      // 1. 获取服务端心愿单
      const response = await fetch('/api/wishlist');
      const data = await response.json();

      if (data.success) {
        // 2. 清空本地
        wishlistStore.clearWishlist();

        // 3. 从服务端恢复到本地store
        data.data.forEach((item: any) => {
          wishlistStore.addItem({
            productId: item.product.id,
            name: item.product.name,
            price: item.product.price,
            image: item.product.images?.[0]?.url || '',
          });
        });

        console.log(`✅ 心愿单同步完成: ${data.data.length} 件商品`);
      }
    };

    syncWishlistFromServer();
  }
}, [status, session]);
```

**集成**: 添加到 `src/components/providers/root-providers.tsx`

### 问题3: 购物车与用户关联 ✅

**根因**: 原有CartSync只单向同步（本地→服务端），没有恢复功能

**解决方案**: 优化CartSync实现双向同步

**修改文件**: `src/components/cart/cart-sync.tsx`

**核心改进**:

#### 1. 登录后从服务端恢复购物车
```typescript
useEffect(() => {
  if (status === 'authenticated' && session?.user && !restored) {
    const restoreCartFromServer = async () => {
      const response = await fetch('/api/cart');
      const data = await response.json();

      if (data.success && data.data.length > 0) {
        // 清空本地购物车
        clearCart();

        // 从服务端恢复
        data.data.forEach((item: any) => {
          addItem({
            productId: item.product.id,
            name: item.product.name,
            price: item.product.price,
            image: item.product.images?.[0]?.url || '',
            quantity: item.quantity,
            variantId: item.variantId || null,
          });
        });

        console.log(`✅ 购物车恢复完成: ${data.data.length} 件商品`);
      }

      setRestored(true);
    };

    restoreCartFromServer();
  }
}, [status, session, restored]);
```

#### 2. 恢复后同步本地购物车到服务端
```typescript
useEffect(() => {
  if (
    status === 'authenticated' &&
    session?.user &&
    restored &&
    items.length > 0 &&
    !syncedRef.current
  ) {
    const syncCartToServer = async () => {
      await fetch('/api/cart/sync', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ items }),
      });
      
      console.log('✅ 购物车同步完成');
      syncedRef.current = true;
    };

    syncCartToServer();
  }
}, [status, session, items, restored]);
```

**同步流程**:
```
1. 用户登录
   ↓
2. 从服务端恢复购物车到本地store
   ↓
3. 如果本地还有商品（未登录时添加的）
   ↓
4. 同步本地商品到服务端
   ↓
5. 完成双向同步
```

### 问题4: 消息已读状态不持久化 ✅

**根因**: 通知数据只存在内存（useState），刷新后重置

**解决方案**: 使用localStorage持久化通知状态

**修改文件**: `src/components/layout/user-notifications.tsx`

**核心改进**:

#### 1. 从localStorage初始化
```typescript
const [notifications, setNotifications] = useState<Notification[]>(() => {
  if (typeof window === 'undefined') return [];
  const saved = localStorage.getItem('user-notifications');
  if (saved) {
    try {
      return JSON.parse(saved);
    } catch {
      return [];
    }
  }
  return [];
});
```

#### 2. 通知变化时自动保存
```typescript
useEffect(() => {
  if (mounted && notifications.length > 0) {
    localStorage.setItem('user-notifications', JSON.stringify(notifications));
  }
}, [notifications, mounted]);
```

#### 3. 标记已读会自动触发保存
```typescript
const markAsRead = (id: string) => {
  setNotifications(prev =>
    prev.map(n => (n.id === id ? { ...n, read: true } : n))
  );
  // notifications变化 → 触发useEffect → 保存到localStorage
};
```
