# 移动端宽度溢出修复 - 2025-11-18

## 问题描述

移动端页面右侧出现很大的缝隙，页面整体被撑开，导致出现横向滚动条，影响用户体验。

### 问题截图分析
- 移动端显示时，内容区域右侧有明显的空白区域
- 页面可以横向滚动
- 内容没有充满整个屏幕宽度

### 问题根源

这是一个常见的移动端响应式设计问题，通常由以下原因导致：

1. **某些元素宽度超出视口宽度**
   - 固定宽度的元素（如 `width: 1200px`）
   - 未设置 `max-width` 的容器
   - padding 和 margin 导致的额外宽度

2. **动画和过渡效果**
   - 使用 `translateX()` 的轮播动画
   - 元素在动画过程中超出容器边界

3. **容器未设置溢出隐藏**
   - 父容器没有设置 `overflow-x: hidden`
   - 允许子元素溢出显示

## 修复方案

### 1. 全局样式修复 (`src/app/globals.css`)

#### 修改内容
为 `html` 和 `body` 元素添加防止横向滚动的样式：

```css
/* 防止页面横向滚动 - 修复移动端宽度溢出问题 */
html {
  overflow-x: hidden;
  max-width: 100vw;
}

body {
  background-color: hsl(var(--background));
  color: hsl(var(--foreground));
  font-feature-settings: "rlig" 1, "calt" 1;
  /* 允许全站文本被选择（组件内若需要可单独使用 select-none 覆盖） */
  -webkit-user-select: text;
  -moz-user-select: text;
  -ms-user-select: text;
  user-select: text;
  /* 防止页面横向滚动 */
  overflow-x: hidden;
  max-width: 100vw;
  position: relative;
}
```

#### 作用说明
- `overflow-x: hidden` - 隐藏横向溢出的内容
- `max-width: 100vw` - 限制最大宽度为视口宽度
- `position: relative` - 为绝对定位的子元素提供定位上下文

## 技术细节

### overflow-x: hidden 的作用

- **隐藏溢出内容**：当子元素宽度超出父容器时，超出部分会被隐藏
- **阻止横向滚动**：用户无法横向滚动查看溢出的内容
- **保持布局稳定**：防止动态内容导致的布局抖动

### max-width: 100vw 的作用

- **限制最大宽度**：确保元素宽度不超过视口宽度
- **响应式适配**：在不同设备上都能正确显示
- **配合 overflow 使用**：与 overflow-x 配合使用效果更佳

### 为什么多层添加溢出隐藏？

采用**防御性编程**策略：

1. **全局层面**（html/body）- 最外层防护
2. **布局层面**（layout container）- 布局容器防护
3. **组件层面**（header/footer/sections）- 各个组件独立防护

这样即使某个层级出现问题，其他层级仍能防止溢出。

## 注意事项

### 1. 使用 overflow: hidden 的副作用

**可能的问题：**
- 下拉菜单可能被裁剪
- 工具提示（tooltip）可能不完整显示
- 需要溢出显示的内容会被隐藏

**解决方案：**
- 对需要溢出显示的组件（如下拉菜单、弹窗）使用 Portal
- 使用 `position: fixed` 或 `position: absolute` 配合较高的 z-index
- 在特定组件内覆盖 overflow 设置

### 2. 移动端触摸滚动

**保留纵向滚动：**
```css
/* 只隐藏横向溢出，保留纵向滚动 */
overflow-x: hidden;
overflow-y: auto;  /* 或默认的 visible */
```

### 3. 性能考虑

**优化建议：**
- `overflow: hidden` 会创建新的 BFC（块级格式化上下文）
- 对性能影响很小，可以放心使用
- 避免在大量元素上使用 `will-change` 属性
