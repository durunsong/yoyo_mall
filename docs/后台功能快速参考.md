## 📝 常用操作

### 查看数据趋势
```
1. 访问 /admin/analytics
2. 选择时间周期(7/30/90天)
3. 查看各类图表
4. 分析数据趋势
```

### 添加商品
```
1. 访问 /admin/products
2. 点击"添加商品"
3. 填写商品信息
4. 上传商品图片
5. 选择商品状态
6. 保存商品
```

### 处理订单
```
1. 访问 /admin/orders
2. 筛选待处理订单
3. 点击"详情"查看
4. 点击"更新状态"
5. 选择新状态
6. 确认更新
```

### 批量操作商品
```
1. 访问 /admin/products
2. 勾选多个商品
3. 点击"批量操作"
4. 选择操作类型
5. 确认执行
```

### 导出订单数据
```
1. 访问 /admin/orders
2. 筛选需要导出的订单
3. 点击"导出数据"
4. 选择格式(CSV/JSON)
5. 下载文件
```

### 配置系统设置
```
1. 访问 /admin/settings
2. 选择设置标签页
3. 修改配置项
4. 点击"保存设置"
5. 确认保存成功
```

## 🎨 UI 组件库

### 图表组件
```tsx
// 折线图
<LineChart
  data={{ xAxis: [], series: [] }}
  height={300}
  yAxisFormatter={(v) => `$${v}`}
/>

// 柱状图
<BarChart
  data={{ xAxis: [], series: [] }}
  height={300}
  horizontal={false}
/>

// 饼图
<PieChart
  data={[{ name: '', value: 0 }]}
  height={350}
  showPercentage={true}
/>
```

### 图片上传
```tsx
<ImageUpload
  value={images}
  onChange={setImages}
  maxFiles={5}
  disabled={false}
/>
```

### 批量操作
```tsx
<BulkActions
  selectedCount={selected.length}
  totalCount={total}
  onSelectAll={handleSelectAll}
  onClearSelection={handleClear}
  onBulkDelete={handleDelete}
/>
```

### 数据导出
```tsx
<ExportButton
  data={orders}
  filename="orders"
  disabled={loading}
/>
```

## 🐛 故障排除

### 图表不显示
```
1. 检查网络连接
2. 清除浏览器缓存
3. 刷新页面
4. 检查控制台错误
```

### 图片上传失败
```
1. 检查文件格式(JPG/PNG/GIF)
2. 检查文件大小(< 5MB)
3. 检查网络连接
4. 查看错误提示
```

### 数据导出失败
```
1. 检查数据是否为空
2. 检查浏览器下载权限
3. 尝试更换浏览器
4. 查看控制台错误
```
