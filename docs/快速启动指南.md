# YOYO Mall 快速启动指南

## 📋 前置要求

确保你的开发环境已安装：

- Node.js 18+ 
- pnpm (推荐) 或 npm
- PostgreSQL 数据库
- Git

## 🚀 快速启动步骤

### 1. 克隆项目

```bash
git clone <your-repo-url>
cd yoyo_mall
```

### 2. 安装依赖

```bash
pnpm install
# 或
npm install
```

### 3. 配置环境变量

复制环境变量示例文件：

```bash
cp .env.example .env.local
```

编辑 `.env.local` 文件，填入必要的配置：

```env
# 数据库配置 - 必填
DATABASE_URL="postgresql://username:password@localhost:5432/yoyo_mall"

# NextAuth配置 - 必填
NEXTAUTH_SECRET="your-super-secret-key-here"  # 可以运行: openssl rand -base64 32
NEXTAUTH_URL="http://localhost:3000"

# 支付配置 - 可选（用于支付功能）
STRIPE_PUBLIC_KEY="pk_test_..."
STRIPE_SECRET_KEY="sk_test_..."
STRIPE_WEBHOOK_SECRET="whsec_..."

# 文件存储 - 可选
CLOUDINARY_CLOUD_NAME="your_cloud_name"
CLOUDINARY_API_KEY="your_api_key"
CLOUDINARY_API_SECRET="your_api_secret"

# 应用配置
NEXT_PUBLIC_APP_URL="http://localhost:3000"
NEXT_PUBLIC_APP_NAME="YOYO Mall"
```

### 4. 初始化数据库

```bash
# 生成 Prisma Client
pnpm db:generate

# 推送数据库模型
pnpm db:push

# 填充初始数据
pnpm db:seed
```

### 5. 启动开发服务器

```bash
pnpm dev
```

访问 [http://localhost:3000](http://localhost:3000) 查看应用。

## 🛠️ 常用命令

### 开发命令

```bash
pnpm dev          # 启动开发服务器
pnpm build        # 构建生产版本
pnpm start        # 启动生产服务器
pnpm lint         # 代码检查
pnpm type-check   # TypeScript 类型检查
```

### 数据库命令

```bash
pnpm db:generate  # 生成 Prisma Client
pnpm db:push      # 推送数据库模型（开发环境）
pnpm db:migrate   # 创建数据库迁移（生产环境）
pnpm db:seed      # 填充种子数据
pnpm db:studio    # 打开 Prisma Studio
```

## ❓ 常见问题

### 数据库连接失败

检查：
1. PostgreSQL 服务是否运行
2. DATABASE_URL 配置是否正确
3. 数据库是否已创建

```bash
# 创建数据库（在 PostgreSQL 中）
createdb yoyo_mall
```

### 依赖安装问题

清除缓存并重新安装：

```bash
rm -rf node_modules pnpm-lock.yaml
pnpm install
```

### 端口被占用

修改启动端口：

```bash
pnpm dev -- -p 3001
```

1. **创建功能分支**
   ```bash
   git checkout -b feature/your-feature-name
   ```

2. **开发和测试**

   ```bash
   git add .

   git push origin feature/your-feature-name
   ```
