## ✅ 2. 商品管理 API

- ✅ **状态**: 正常
- **权限**: 公开

  - price (价格,≥0)
  - categoryId (分类ID)
- **可选字段**:

  - brandId (品牌ID)
  - status (状态,默认DRAFT)

  - metaDesc (SEO描述)
  - tags (标签数组)
- **自动生成**:
  - slug (URL标识)
  - 库存记录(如果启用trackInventory)
- **测试结果**: ✅ 通过
