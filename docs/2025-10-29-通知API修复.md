## 🐛 问题描述

```
GET http://localhost:3000/api/admin/notifications 500 (Internal Server Error)
```

## 🔍 问题分析

### 根本原因

通知 API 在查询低库存商品时使用了错误的字段:

**错误的代码**:
```typescript
const lowStockProducts = await prisma.product.findMany({
  where: {
    stock: {              // ❌ Product 模型没有 stock 字段
      lte: 10,
    },
    published: true,      // ❌ Product 模型没有 published 字段
  },
  select: {
    id: true,
    name: true,
    stock: true,          // ❌ 错误字段
  },
});
```

### Prisma Schema 实际定义

#### Product 模型
```prisma
model Product {
  id              String        @id @default(cuid())
  name            String
  slug            String        @unique
  description     String?
  sku             String        @unique
  price           Decimal       @db.Decimal(10, 2)
  categoryId      String
  brandId         String?
  status          ProductStatus @default(DRAFT)  // ✅ 使用 status 而不是 published
  // ... 其他字段
  
  inventory     Inventory?     // ✅ 库存在独立的 Inventory 表中
}
```

#### Inventory 模型
```prisma
model Inventory {
  id                String   @id @default(cuid())
  productId         String?  @unique
  variantId         String?  @unique
  quantity          Int      @default(0)           // ✅ 库存数量
  reservedQuantity  Int      @default(0)
  lowStockThreshold Int      @default(10)
  createdAt         DateTime @default(now())
  updatedAt         DateTime @updatedAt
  
  product Product?        @relation(fields: [productId], references: [id])
  variant ProductVariant? @relation(fields: [variantId], references: [id])
}
```

#### ProductStatus 枚举
```prisma
enum ProductStatus {
  DRAFT       // 草稿
  PUBLISHED   // 已发布 ✅
  ARCHIVED    // 已归档
}
```

## 🔧 修复方案

### 修改前
```typescript
// 获取低库存商品
const lowStockProducts = await prisma.product.findMany({
  where: {
    stock: {              // ❌ 错误字段
      lte: 10,
    },
    published: true,      // ❌ 错误字段
  },
  select: {
    id: true,
    name: true,
    stock: true,          // ❌ 错误字段
  },
  orderBy: {
    stock: 'asc',         // ❌ 错误字段
  },
  take: 5,
});

// 构建通知
...lowStockProducts.map((product) => ({
  id: `stock-${product.id}`,
  type: 'product' as const,
  title: '库存预警',
  message: `商品 "${product.name}" 库存不足,当前库存: ${product.stock}`, // ❌ 错误字段
  url: `/admin/products?id=${product.id}`,
  read: false,
  createdAt: new Date().toISOString(),
})),
```

### 修改后
```typescript
// 获取低库存商品(通过 inventory 表查询)
const lowStockProducts = await prisma.product.findMany({
  where: {
    status: 'PUBLISHED',  // ✅ 使用 status 字段
    inventory: {          // ✅ 通过 inventory 关联查询
      quantity: {         // ✅ 使用 quantity 字段
        lte: 10,
      },
    },
  },
  select: {
    id: true,
    name: true,
    inventory: {          // ✅ 包含 inventory 数据
      select: {
        quantity: true,   // ✅ 选择 quantity 字段
      },
    },
  },
  orderBy: {
    inventory: {          // ✅ 按 inventory.quantity 排序
      quantity: 'asc',
    },
  },
  take: 5,
});

// 构建通知
...lowStockProducts.map((product) => ({
  id: `stock-${product.id}`,
  type: 'product' as const,
  title: '库存预警',
  message: `商品 "${product.name}" 库存不足,当前库存: ${product.inventory?.quantity || 0}`, // ✅ 使用 inventory.quantity
  url: `/admin/products?id=${product.id}`,
  read: false,
  createdAt: new Date().toISOString(),
})),
```

## 📊 数据库结构说明

### 商品库存管理

YoYo Mall 使用独立的 `Inventory` 表来管理库存:

```
Product (商品表)
  ├── id
  ├── name
  ├── status (DRAFT/PUBLISHED/ARCHIVED)
  └── inventory (关联到 Inventory 表)

Inventory (库存表)
  ├── id
  ├── productId (关联到 Product)
  ├── variantId (关联到 ProductVariant,可选)
  ├── quantity (库存数量) ✅
  ├── reservedQuantity (预留数量)
  └── lowStockThreshold (低库存阈值,默认 10)
```

### 优势
1. **灵活性**: 商品和变体都可以有独立的库存
2. **可扩展性**: 可以添加更多库存相关字段
3. **性能**: 库存查询不影响商品查询
4. **数据完整性**: 库存数据独立管理

## 📝 最佳实践

### 1. 使用正确的字段名

**❌ 错误**:
```typescript
product.stock         // Product 模型没有 stock 字段
product.published     // Product 模型没有 published 字段
```

**✅ 正确**:
```typescript
product.inventory?.quantity  // 通过 inventory 关联获取库存
product.status              // 使用 status 字段判断发布状态
```

### 2. 处理可选关联

由于 `inventory` 是可选的,使用时要处理 `null` 情况:

```typescript
// ✅ 使用可选链和默认值
const quantity = product.inventory?.quantity || 0;

// ✅ 使用条件判断
if (product.inventory) {
  const quantity = product.inventory.quantity;
}
```

### 3. 查询时包含关联数据

```typescript
// ✅ 使用 include
const products = await prisma.product.findMany({
  include: {
    inventory: true,
  },
});

// ✅ 使用 select
const products = await prisma.product.findMany({
  select: {
    id: true,
    name: true,
    inventory: {
      select: {
        quantity: true,
      },
    },
  },
});
```

## 🐛 常见错误

### 错误 1: 直接访问不存在的字段
```typescript
// ❌ 错误
product.stock

// ✅ 正确
product.inventory?.quantity
```

### 错误 2: 使用错误的状态字段
```typescript
// ❌ 错误
where: { published: true }

// ✅ 正确
where: { status: 'PUBLISHED' }
```

### 错误 3: 忘记处理 null 值
```typescript
// ❌ 错误 - 可能抛出错误
product.inventory.quantity

// ✅ 正确 - 使用可选链
product.inventory?.quantity || 0
```
