## 🔧 实现细节

### Input组件增强

**clearable 模式**:
```tsx
<Input
  clearable
  value={value}
  onChange={(e) => setValue(e.target.value)}
  onClear={() => {
    setValue('');
    // 其他清空逻辑
  }}
/>
```

**布局结构**:
```tsx
<div className="relative">
  <SearchIcon /> {/* 左侧图标 */}
  <Input clearable className="pl-10 pr-10" />
  <ClearButton /> {/* 右侧清空按钮 */}
  <LoadingIcon /> {/* 右侧加载图标 */}
</div>
```

### 图标定位优化

为了避免清空按钮与其他图标冲突，使用了以下策略：

1. **左侧图标**: `left-3` + `z-10`
2. **清空按钮**: `right-2` (由Input组件内部处理)
3. **加载图标**: `right-10` + `z-10` (留出清空按钮的空间)
4. **输入框padding**: `pl-10 pr-10` (两侧都留出空间)

## 💡 使用建议

### 推荐使用场景

✅ **适合**:
- 搜索框
- 筛选输入框
- 表单文本字段
- 用户名/邮箱等可编辑字段

❌ **不建议**:
- 密码输入框（已有显示/隐藏功能）
- 验证码输入（简短且重要）
- 日期选择器（有专门的清空机制）
- 数字输入（有增减按钮）

### 快速添加方法

对于任何需要清空功能的输入框：

```tsx
// 1. 找到 Input 组件
<Input placeholder="搜索..." />

// 2. 添加 clearable 属性
<Input clearable placeholder="搜索..." />

// 3. （可选）添加 onClear 回调
<Input
  clearable
  placeholder="搜索..."
  onClear={() => {
    // 自定义清空逻辑
  }}
/>
```
