### 二、搜索功能

#### 组件
- `src/components/admin/admin-search.tsx` - 搜索组件
- `src/app/api/admin/search/route.ts` - 搜索 API

#### 功能特性
- ✅ 实时搜索(300ms 防抖)
- ✅ 搜索商品、订单、用户
- ✅ 键盘导航支持
- ✅ 点击外部关闭
- ✅ 搜索结果分类显示

#### 搜索范围
- **商品**: 名称、SKU、描述
- **订单**: 订单号、用户名、邮箱
- **用户**: 姓名、邮箱

---

### 三、通知功能

#### 组件和页面
- `src/components/admin/admin-notifications.tsx` - 通知组件
- `src/app/admin/notifications/page.tsx` - 通知中心页面
- `src/app/api/admin/notifications/route.ts` - 通知列表 API
- `src/app/api/admin/notifications/[id]/read/route.ts` - 标记已读 API
- `src/app/api/admin/notifications/read-all/route.ts` - 全部已读 API

#### 功能特性
- ✅ 实时通知提醒
- ✅ 未读数量徽章
- ✅ 下拉式通知列表
- ✅ 标记已读/未读
- ✅ 删除通知
- ✅ 全部标记为已读
- ✅ 点击跳转详情
- ✅ 自动刷新(每60秒)

#### 通知类型
- 🛒 **订单通知**: 最近24小时的新订单
- 📦 **商品通知**: 库存≤10的预警
- 👤 **用户通知**: 最近24小时的新用户
- ⚠️ **系统通知**: 系统消息

## 🎯 使用方法

### 搜索功能
```
1. 在后台顶部搜索框输入关键词
2. 查看实时搜索结果
3. 使用 ↑↓ 键选择
4. 按 Enter 或点击跳转
5. 按 ESC 关闭
```

### 通知功能
```
1. 点击顶部通知图标
2. 查看未读数量徽章
3. 浏览通知列表
4. 点击通知跳转详情
5. 标记已读或删除
6. 访问通知中心查看全部
```
