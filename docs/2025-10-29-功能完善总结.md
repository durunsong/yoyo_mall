- ✅ 删除OSS存储的头像文件
- ✅ 数据库设置为null

#### 配置信息
```env
OSS_ACCESS_KEY_ID=LTAI5t5xAMmPtdEjHqGx9h5W
OSS_ACCESS_KEY_SECRET=M3Tii8l9acudWgtQkOVJ23V3UDj6sZ
OSS_REGION=oss-rg-china-mainland
OSS_BUCKET=next-static-oss
OSS_FOLDER=yoyo_mall
```

#### 技术实现
```typescript
// 使用 sharp 进行图片压缩
const compressedBuffer = await sharp(buffer)
  .resize(1920, 1080, { fit: 'inside' })
  .jpeg({ quality: 85, mozjpeg: true })
  .toBuffer();

// 生成缩略图
const thumbnailBuffer = await sharp(buffer)
  .resize(200, 200, { fit: 'cover' })
  .jpeg({ quality: 80, mozjpeg: true })
  .toBuffer();

// 上传到OSS
const result = await oss.upload({
  file: buffer,
  filename: file.name,
  folder: OSS_FOLDERS.AVATARS,
  compress: true,
  generateThumbnail: true,
});
```

### 2.4 发现的问题

#### ⚠️ 优惠券字段访问错误

**位置**: `src/app/api/orders/route.ts:302`

**错误代码:**
```javascript
usageLimit: { gt: prisma.coupon.fields.usageCount }
```

**修复建议:**
```javascript
// 先查询优惠券
const coupon = await prisma.coupon.findFirst({
  where: {
    code: data.couponCode,
    isActive: true,
    validFrom: { lte: new Date() },
    validTo: { gte: new Date() },
  },
});

// 手动检查使用次数
if (!coupon) {
  return error('INVALID_COUPON', '优惠券无效或已过期');
}

if (coupon.usageCount >= coupon.usageLimit) {
  return error('COUPON_LIMIT_REACHED', '优惠券使用次数已达上限');
}
```
