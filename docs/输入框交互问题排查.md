# 输入框交互问题排查指南

**日期**: 2025-10-28  
**问题**: 输入框内容无法选中、局部复制和一键清除  
**状态**: 🔍 排查中

## 问题描述

用户反馈：项目中所有的输入框（Input）的内容都无法选中和局部复制，也无法一键清除。

## 初步排查结果

### ✅ 代码检查 - 正常

1. **Input 组件** (`src/components/ui/input.tsx`)
   - ✅ 没有禁用选择的样式
   - ✅ 使用标准的 `<input>` 元素
   - ✅ 没有 `user-select: none` 样式

2. **全局样式** (`src/app/globals.css`)
   - ✅ 有正常的文本选择样式 `::selection`
   - ✅ 没有禁用选择的全局样式
   - ✅ 没有阻止用户交互的CSS

3. **组件样式**
   - ✅ `select-none` 只用在菜单、标签等非输入组件
   - ✅ Input/Textarea 组件没有禁用选择

## 可能的原因

### 1. 浏览器缓存问题
**症状**: 旧的CSS缓存导致样式异常

**解决方法**:
```bash
# 1. 清除浏览器缓存
Ctrl + Shift + Delete (Chrome/Edge)
Cmd + Shift + Delete (Mac)

# 2. 强制刷新
Ctrl + F5 (Windows)
Cmd + Shift + R (Mac)

# 3. 清除应用缓存
# 在浏览器开发者工具中:
Application → Clear Site Data
```

### 2. 浏览器扩展干扰
**症状**: 某些扩展可能阻止文本选择

**解决方法**:
```
1. 打开无痕/隐私模式测试
2. 禁用所有浏览器扩展
3. 逐个启用查找问题扩展
```

常见干扰扩展：
- 广告拦截器
- 网页自动翻译
- 阅读模式扩展
- 隐私保护扩展

### 3. 操作系统/浏览器设置
**症状**: 系统级别的限制

**解决方法**:
```
检查:
- Windows: 辅助功能设置
- Mac: 系统偏好设置 → 辅助功能
- 浏览器: 设置 → 高级 → 辅助功能
```

### 4. Next.js 开发模式问题
**症状**: 热重载导致事件监听器异常

**解决方法**:
```bash
# 1. 重启开发服务器
Ctrl + C
pnpm dev

# 2. 清除 .next 缓存
rm -rf .next
pnpm dev
```

### 5. React Strict Mode 双重渲染
**症状**: 事件处理器被多次绑定

**排查**: 检查 `src/app/layout.tsx` 中的 StrictMode

### 6. 全局事件监听器
**症状**: JavaScript 阻止了默认的文本选择行为

**排查代码**:
```bash
# 搜索可能阻止选择的代码
grep -r "preventDefault" src
grep -r "stopPropagation" src
grep -r "user-select" src
```

## 临时解决方案

### 方案1: 添加明确的样式（如果需要）

编辑 `src/app/globals.css`，添加：

```css
/* 确保输入框可以选择文本 */
input,
textarea,
[contenteditable="true"] {
  user-select: text !important;
  -webkit-user-select: text !important;
  -moz-user-select: text !important;
  -ms-user-select: text !important;
}

/* 确保输入框内容可复制 */
input::selection,
textarea::selection {
  background-color: hsl(var(--primary));
  color: hsl(var(--primary-foreground));
}
```

### 方案2: 修改 Input 组件

编辑 `src/components/ui/input.tsx`：

```typescript
const Input = React.forwardRef<HTMLInputElement, React.ComponentProps<"input">>(
  ({ className, type, ...props }, ref) => {
    return (
      <input
        type={type}
        className={cn(
          "flex h-9 w-full rounded-md border border-input bg-transparent px-3 py-1 text-base shadow-sm transition-colors file:border-0 file:bg-transparent file:text-sm file:font-medium file:text-foreground placeholder:text-muted-foreground focus-visible:outline-none focus-visible:ring-1 focus-visible:ring-ring disabled:cursor-not-allowed disabled:opacity-50 md:text-sm",
          // 确保可以选择文本
          "select-text",
          className
        )}
        ref={ref}
        // 确保没有阻止默认行为
        onMouseDown={(e) => {
          // 不阻止选择行为
          props.onMouseDown?.(e);
        }}
        {...props}
      />
    )
  }
)
```
